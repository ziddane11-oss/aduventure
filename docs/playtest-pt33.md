# pt33 — 미감 C안(고대비·큰 글씨) 적용

pt32 비교 시안(A 지금 / B 종이책 / C 고대비·큰 글씨) 중 사용자가 **C**를 골라 게임 전체에 적용했다.

| 요소 | pt32 | pt33 |
|---|---|---|
| 본문(`.narr`) | 17px, 기본 글자색 | **19px**, 더 밝은 `#f3ede2` |
| 판정 결과(`.result`) | 15px | **17px** (본문과 비례 유지) |
| 선택지(`button.choice`) | 15px | **17px** + 왼쪽 금색 선 3px |
| 걸린 것(`.stake`) | 12px | **14px** |
| 꼬리표 하나(`.tag.one`) | 12px | **14px** |
| 인물 한마디(`.banter`) | 14px | **16px** |
| 「다른 방법 N개 더」·「다른 방법 제안하기」 | 36–38px 높이 | **최소 44px** (큰 글씨에 맞춰 터치 크기) |

## 검증
- 테스트 261개 통과, 전투 밸런스 시뮬 변화 없음(CSS만 변경).
- 미감 객관 점검(390×844, 8개 화면): 대비 미달 0(장식용 ◆ 구분선 제외), 40px 미만 버튼 0, 가로 넘침 없음.
- 한국어·영어 각각 첫 장면·필사소장 화면 캡처로 글자 잘림 없는지 확인.
- 화면 길이: 큰 글씨로 장 끝 화면이 휴대폰 약 2.7–3.3장 분량 — 길이 줄이기는 별도 과제.
