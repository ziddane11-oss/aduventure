# pt14 — 첫 5초의 훅: "기록은 거짓말을 한다"

## 목적

직접 플레이 피드백: "처음에 '이게 뭐지?' 하는 훅이 부족하다." 기존 첫 1분은 포스터 → 이름 → 규칙 → 능력치 카드 → 촌장의 부탁으로, 질문 없이 준비만 있었다. 우리 맛(한 판엔 안 풀리는 미스터리 · 진실의 대가 · 기록 모티프)이 첫 화면에 없었다.

## 변경

| 장치 | 내용 |
|---|---|
| **틀린 공식 기록** | 첫 화면이 메뉴가 아니라 촌장 세온이 쓴 「소금여울 공식 기록 · 제113호」다. "떠돌이 모험가 1명, 사망. 이름은 기록되지 않았다. … 원인: 불운." 아래에 붉은 손글씨 **거짓말이다.** |
| **첫 선택** | `거짓말이다 — 이 기록을 다시 쓴다` / `기록을 믿는다`. 믿으면 회차 플래그 `believed`가 붙고, 1장 반박에 "처음에 당신은 이 기록을 믿었다."가 앞에 붙는다. |
| **기록에 남을 이름** | 이름 입력 문구를 "기록에 남을 이름은?"으로 바꿨다. 도감·지식·유물 목록은 「기록 보관소」로 접었다. |
| **회차 = 기록 번호** | 새 회차마다 제113호, 114호…(`aduventure_record_no`). 1장 배너에 "기록 제N호". 저장에 `runNo`를 추가했다(구 저장은 번호 없이 이어진다). |
| **지난 기록 한 줄** | 다음 회차 첫 화면에 "제113호의 당신은 렌을 붙잡고 렌즈를 잃었다. 이번 기록은?"(`aduventure_lastrun`). 가장 결정적인 행동 하나를 고른다(고발 > 수문 > 죽음 > 난간). |
| **장마다 공식 기록 vs 반박** | 각 장 엔딩에 세온의 공식 기록 카드를 놓고, 플레이어가 아는 조각이 있을 때만 붉은 손글씨 반박을 단다. 에필로그는 선택에 따라 **기록자가 바뀐다**: 고발 = "(정정) 기록자: {이름}", 희생 = 거짓 기록 + "그대로 두었다", 거래 = "함께 서명함". |
| **게임오버** | "기록대로 되었다" 도장이 찍힌 기록 + `이 기록을 다시 쓴다` 버튼. 죽음이 첫 화면의 예언을 실현한다. |
| **실시간 반박** | 조각을 얻으면 결과에 `✎ 반박 기록 — …`가 붙는다. |
| **기록 공유** | 엔딩마다 `📋 이 기록 복사하기`: 공식 기록·반박·게임 주소를 평문으로 복사한다(이름 외 개인 정보 없음). |
| **첫 화면 압축** | 기록 화면에서는 포스터를 등대 띠로 줄여 첫 선택이 휴대폰 첫 화면 안에 들어오게 했다. |

텔레메트리 `run_start`에 `opening`(lie/believe)과 `record_no`를 더했다. 첫 화면 이탈과 태도별 진행을 비교할 수 있다.

## 검증 (2026-10-01)

- 자동 테스트 **133개 통과**: 기존 123개 + `tests/record.test.cjs` 10개. 기존 2개 테스트는 첫 화면 순서 변경에 맞춰 기록 선택을 먼저 누르도록 고쳤다.
- 전투 54조건 결과는 pt10과 동일하다.
- Chromium 390×844: **첫 선택이 페이지 로드 0.4초 뒤 첫 화면 안에** 보인다(이전에는 포스터 아래로 밀려 있었다). 1장 엔딩 기록·반박, 기록 복사(클립보드 첫 줄 `[소금여울 공식 기록 · 제113호]`), 영어 전환 시 한글 없음, 다음 방문 제114호와 지난 기록 한 줄, 페이지 오류 0, 가로 넘침 없음.
- **미확인:** 실제 휴대폰 클립보드 권한, 첫 화면을 본 사람이 실제로 "이게 뭐지?"를 느끼는지.

## 측정 질문

1. 첫 화면에서 이탈하는 비율(기록 화면 → run_start)과 첫 선택까지의 시간.
2. `기록을 믿는다`를 고르는 비율. 높으면 기록이 너무 그럴듯하다는 뜻이고, 0%면 선택이 장식이다.
3. 플레이 후 "이 게임을 한 문장으로?"에 "기록/거짓말/다시 쓴다"가 나오는가.

## 남은 문제

- 첫 화면 문구는 Claude 초안이다. 작가의 문장으로 바꿀 1순위 자리다(윤문 패스).
- 웹소설 「기록되지 않은」 링크는 주소를 확인하지 못해 넣지 않았다.
