## 바꾼 것
- **이어 가기 버튼을 위로**: 장 끝 화면에서 `계속 →`·`결론을 내린다` 버튼이 의뢰·지킨 것·기록 범위·도감·통계·오늘의 도전(블록 7개) 아래에 묻혀 있었다. 이제 순서는 서사 → 공식 기록 → 이의 있음 → 보상 알림(새 배지·최고 기록·유물) → **버튼** → 「📜 이번 장 정리」.
- **정리는 접기**(지우지 않음): 요약줄에 `✓지킨 것 · ✗잃은 것 · 의뢰 n/3 · 엔딩 도감 x/y`. 펼친 상태는 기억(`aduventure_endmore`).
- **이의 있음 시작 전**: 제목(✒ 이의 있음)과 버튼 글자가 겹쳐 두 줄이던 것을 버튼 하나로. 누르면 지금처럼 제목과 함께 펼쳐진다.
- **개인 최고 기록 알림**: 두 줄 설명 → `★ 개인 최고 기록!` 한 줄(설명은 접힌 「기록 범위」에 그대로).
