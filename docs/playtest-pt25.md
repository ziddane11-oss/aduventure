# pt25 — 휴대폰 한 손 플레이(위아래 오가기 줄이기)

## 왜
플레이 피드백(휴대폰): "스크롤 왔다갔다 해야 되는 건 어쩔 수 없나?" + 스크린샷에서 **위에 붙어 따라오는 큰 그림 카드(약 150px)가 첫 선택지를 가리는** 문제 확인.

## 무엇(700px 이하 화면)
1. 큰 그림은 더 이상 따라오지 않는다. 대신 **한 줄 막대(장소 + 체력 막대 + 숫자, 약 35px)**만 위에 붙는다.
2. **고른 뒤 자동 위치 맞춤**: 장면이 바뀌면 판정 결과(없으면 새 장면 첫 줄)가 한 줄 막대 바로 아래로 오도록 부드럽게 스크롤(이미 맨 위면 그대로).
3. 캐릭터 카드를 한 줄로: 여백 축소, '체력' 글자·단서 줄은 휴대폰에서 숨김(단서는 사건 기록장에 그대로). 무대 그림 높이 120→104px.

## 결과(390×844 재현)
- 고르기 전: 한 줄 막대 아래 35px부터, 선택지는 382px부터 — 가려지는 선택지 없음.
- 고른 뒤: 결과가 화면 35px(막대 바로 아래)에 위치 — 결과 + 새 장면 + 선택지 전부가 한 화면.
