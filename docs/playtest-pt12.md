# pt12 — 상태에 반응하는 배경음과 선택 직전의 '걸린 것'

## 목적

pt11 직접 플레이 피드백: "무난하다. 고민되거나 반갑지는 않았고, 결과 카드는 궁금했다. BGM이 있으면 좋겠다." 플레이어 한 명의 의견이므로 큰 구조 변경 대신 두 가지만 넣는다.

1. **배경음(BGM)** — 음원 파일 없이 WebAudio로 생성해 단일 HTML·CDN 0을 유지한다. 기존 소리 토글(🔇/🔊)을 따르며 기본은 꺼짐이다.
2. **걸린 것 예고** — 무거운 선택지 아래에 고르기 전에 무엇을 잃는지 한 줄로 보여 준다. 대가가 고른 뒤에만 보여 고민이 생기지 않았다는 가설을 검증한다.

## 배경음 규칙 (`bgmMood`, 순수 함수)

| 상태 | 소리 |
|---|---|
| 1장 / 2장 / 3장 | 빗소리 + 낮은 A / 파도 + D / 오르간 같은 C 화음 |
| 난간·수문(`railing`, `rescue`)·봉화(`signal`) | 저음이 빠지고 빗소리가 줄어든다 — 선택 직전의 정적 |
| 전투 중 | 긴장 저음 45%. 렌이 '갈고리 강타'를 예고하면 100%로 차오른다 |
| HP ≤ 1/3 | 심장박동 104 bpm. 전투 중 HP ≤ 1/2이면 76 bpm |
| 게임오버 | 빗소리만 남는다 |

기존의 단독 빗소리 루프를 이 층으로 대체했다. 효과음(주사위·성공·실패·종)은 그대로다.

## 걸린 것

`stake: { ko, en }`를 가진 선택지는 버튼 아래에 "걸린 것 · …"을 표시한다. 렌 전투 시작, 난간 두 선택, 철사 수리, 3장 수문의 사람/증거.

## 검증 (2026-10-01)

- 자동 테스트 **108개 통과**: 기존 98개 + `tests/bgm.test.cjs` 10개. 장·정적·긴장·심장박동 규칙, 가짜 AudioContext에서 테마 전환 시 이전 음 정지·긴장 이득·박동 간격·끄면 모든 음과 타이머 정지, Web Audio가 없는 환경에서 예외 없음, 한·영 '걸린 것' 렌더.
- 전투 54조건 결과는 pt10·pt11과 동일하다.
- Chromium(390×844, 사용자 제스처 필요 자동재생 정책): 소리 켜기 → AudioContext `running`, 1장 테마, 전투에서 긴장 저음, 난간에서 저음 0, 끄면 노드 해제. 페이지 오류 0, 가로 넘침 없음.
- **미확인:** 실제 귀로 들은 음색과 음량, 휴대폰 스피커·무음 스위치(iOS) 동작.

## 남은 문제

- 음색은 수치로만 조정했다. 실제로 들어 보고 음량·음정을 고쳐야 한다.
- '걸린 것'이 고민을 만드는지, 오히려 답을 알려 주는지는 테스터 관찰로 확인한다.
