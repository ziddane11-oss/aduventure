# pt31 — 테스터 1000명 + "어떻게 하면 끝까지 해서 사겠어요?" 인터뷰

## 왜
"3번(성격 다른 AI 평가자)에게 게임을 어떻게 하면 끝까지 완결해서 엔딩 보고 구입하겠냐고 물어봐. 테스터 1000명으로 늘리자."

## 어떻게
- `tools/persona-sim.cjs`에 유형 2개를 추가해 **12유형**이 됐다: 깐깐한 스팀 리뷰어, 인터랙티브 픽션 비평가(둘 다 영어).
- 실제 게임 코드로 **1000명**을 돌렸다(약 2분 40초).
- 1000명을 **어디까지 갔나 × 유형**으로 묶고, 묶음마다 대표 1명씩 17명을 뽑았다.
- 대표 17명은 실제 장면 문장을 읽고 같은 질문에 1인칭으로 답했다. 답은 묶음 크기(n)로 가중했다.

## 1000명(pt30) — 어디까지 갔나
| 묶음 | 인원 |
|---|---|
| A 사건 2까지 | 389 |
| B 판결까지(사건 2 전) | 25 |
| **C 3장은 끝냈는데 판결 못 감** | **467** |
| D 3장 전 이탈(대부분 모바일 초보·고등학생) | 119 |

## 구입 의향(대표 17명)
- **지금 산다: 0명.**
- **고치면 산다: 11명.** 4,000~8,000원 또는 $3.99~$12.
- **안 산다 / 무료여야: 6명.** 스피드러너, 모바일 초보, 고등학생 ×2, 스팀 리뷰어(사망 경험).
- 가장 큰 공통 이유:
  1. 사건 2가 1장에서 끊긴다 — "데모지 제품이 아니다".
  2. 판결로 가는 길이 막히거나 보이지 않는다.
  3. 반복과 사망 때 1장부터 다시 해야 한다.

## 인터뷰에서 나온 것 → 확인 → 이번에 고친 것
| 요구(가중 인원) | 확인 | 조치 |
|---|---|---|
| **판결 경로 막다른 길**(262) — 「2장 아침으로 — 베른에게 묻는다」를 눌렀는데 베른에게 묻는 선택지가 없음 | 맞음(**pt29 수정이 만든 구멍**): 그 선택지는 조각 3개 이상일 때만 보였고, 아니면 숨겨짐 | 숨기지 않고 **🔒 조각 n/3**로 잠가 보인다. 3장 끝 안내는 조각 3개 이상일 때만 「2장 아침으로」를 띄운다. 아니면 이유 한 줄과 함께 「3장 다시」를, 3장 조각을 이미 다 가졌으면 「처음부터」를 강조한다 |
| **엔딩 화면에 다음 할 일이 묻힘**(222) | 맞음: 기록 카드·반박·장부·배지 아래 맨 끝에 있었음 | 3장 엔딩 **맨 위에 「다음 할 일」** 한 줄 |
| **죽으면 1장부터**(199) | 맞음: 사망 → 첫 화면·직업 선택 | **「이 장 처음부터 다시 쓴다」**(앞 장의 일은 유지) + 「처음부터 새 기록으로」 |
| **시간 초과가 죽음으로**(199) | 맞음: 망설임 → 첫 판정의 실패 → `ifDown: gameover` 가능 | 망설임으로는 **쓰러지지 않는다**(체력 1에서 멈춤). **첫 기록에는 시간 제한이 없다**(두 번째 기록부터) |
| **추론 피드백이 인색**(209) — 30분에 한 번 | 맞음 | 추론 확인을 **장마다 한 번**으로 |
| 반박이 왜 틀렸는지 모름 | 맞음 | 틀린 증거에 "'(그 증거가 보여 주는 것)' — 그건 이 줄과 부딪치지 않는다" |

## 고치지 않은 것(선생님 판단이 필요)
1. **사건 2 완결**(190) — 구입을 막는 1순위 이유. 로드맵 M2 분량이다.
2. **첫 판에 판결까지**(194) — "한 번 쭉 하면 판결, 반복은 더 좋은 결말용". 사건 구조(여러 판 필요)를 바꾸는 결정이다.
3. **판결이 추리가 아니라 거래**(70, 추리광) — [희생]/[거래]가 도덕 선택이라 "맞히는 맛"이 약하다는 지적.
4. **[희생] 후일담이 짧다**(이야기 몰입형).

## 한계
- 묶음 대표 17명의 답은 같은 AI가 쓴 것이다. 가격·구입 의향은 **참고용**이다 ⚠추론.
- 1000명 시뮬은 구조 문제를 잘 잡지만 재미 자체는 재지 못한다.
