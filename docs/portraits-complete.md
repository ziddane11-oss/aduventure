# pt44.1 — 누락된 초상 6명 완성

기존에는 세온·베른·렌만 생성 이미지가 연결돼 있었고, 나머지 6명은 도형 초안으로 표시됐다.

- 스컬리·오도·핍·회색 형제·이레·묵을 같은 잉크 판화풍으로 개별 제작하고 `PORTRAIT_FILES`에 연결했다.
- 각 이미지 512×512 WebP. 새 파일 6개 합계 353,226바이트(약 345 KiB).
- 기존 생성 이미지 3장은 유지했다. 이미지 로드 실패 시 도형 초상으로 돌아가는 동작도 유지했다.
- 한국어·영어 초상 크레딧을 9명 전체로 갱신했다.
- 기존 테스트에서 의도한 도형 대체 화면을 확인하도록, 테스트에 명시적으로 빈 이미지 경로 맵을 주입했다.
- 게임 규칙·대사·분기·저장 형식은 그대로다. `letter.html`은 같은 게임을 열고, itch.io 패키지 생성 스크립트는 `art/`의 새 파일을 함께 포함한다.

제작 방식: ChatGPT 내장 이미지 생성. [공통 프롬프트와 인물별 프롬프트](portrait-prompts-complete.md). 원본은 유지하며 배포용 크기·포맷만 최적화했다.

## 검증

- 기존 자동 검사 321개 통과.
- 여섯 인물의 실제 장면 렌더 입력에서 파일 경로와 한·영 대체 텍스트, 로드 실패 시 도형 대체를 확인했다.
- 배포용 이미지 파일 6개를 검사하고, itch.io 패키지에 9명 이미지가 모두 포함되는 것을 확인했다.
- 브라우저의 공개 버전 확인은 배포 후 진행한다. 로컬 화면 검사는 이 환경의 브라우저 실행 제한으로 완료하지 못했다.
