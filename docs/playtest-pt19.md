# pt19 — 직업의 길: 직업마다 다른 길, 다른 단서

## 왜
"직업에 따라 게임 진행에 차이점이 뭐지?" → 확인해 보니 차이는 판정 확률과 HP뿐이었다.
- 직업 전용 선택지: 위저드 4개(결투용 비전학), 파이터·로그 0개
- 판정 41개 중 운동이 12개 → 파이터가 평균 59%로 가장 유리, 위저드 49%
- 다른 직업으로 다시 할 이유가 없었다.

## 무엇 — 장마다 직업 전용 길 1개씩(총 9개), 성공하면 단서 조각
| 직업 | 정체성 | 1장 | 2장 | 3장 |
|---|---|---|---|---|
| ⚔ 파이터 | **둘 다 잡는다** (실패하면 둘 다 잃는다) | 난간: 렌과 렌즈 둘 다 (운동 14) → 렌의 증언 + 반출 확인서 | 창고: 문을 뜯고 장부 (운동 13) → 공동 기금 장부 | 수문: 배달부와 편지 둘 다 (운동 15) → 결정적 조각 2개 |
| 🗡 로그 | **먼저 안다** (싸우기 전에 엿듣고 훔친다) | 계단: 렌의 자루에서 종이만 슬쩍 (은신 12) → 반출 확인서, 싸움 없이 | 부두: 밀수꾼 행세 (기만 12) → 세온의 창문 | 지하: 철창 너머 속삭임 (은신 12) → 수신인 세온 |
| ✦ 위저드 | **꿰뚫어 본다** (흔적을 읽는다) | 등실: 렌즈의 빛 궤적 (비전학 12) → 세온의 창문 + 수리 | 창고 정면: 등불에 불씨 (비전학 12) → 공동 기금 장부 | 지하: 열쇠 꼬리표 글씨 (비전학 12) → 서명 = 꼬리표 |

- 실패하면 단서 없음 + 대가(피해, 싸움, 매복).
- 직업 카드에 "직업의 길" 한 줄, 해당 선택지에 `⚔ 파이터의 길` 꼬리표.
- 사건 기록장의 단서 위치 힌트에 직업별 경로를 덧붙였다.
- '둘 다' 결과는 3장 엔딩·지난 기록 한 줄·렌즈 유물 판정에 반영(`both3`, `bothRail`).
- 플레이테스트 시트의 기존 제안("사람과 증거를 동시에 택하는, 성공확률 낮은 선택지")을 파이터의 길로 반영.

## 보존한 것
- 회차 구조: 어느 직업도 1장에서 조각 3개 이상을 얻지 못한다(테스트로 전수 탐색) → 베른의 고백(조각 3개 필요)은 여전히 2회차 이후.
- 전투 엔진 시뮬레이션: 기준선과 동일.
