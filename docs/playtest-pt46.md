# pt46 — 휴대폰 첫 화면에서 본문을 위로

## 문제

pt45 이후에도 휴대폰(390×844)의 첫 장면에서 본문이 화면 중간쯤부터 시작했다. 본문 위에 상단 아이콘 줄(두 줄로 접혀 115px), 위치·체력 막대, 위치 카드가 얹힌 그림, 이름·직업·체력 줄이 쌓여 있었다. **위치와 체력이 각각 두 번씩** 보였다(막대 + 그림 카드, 막대 + 이름 줄). 외부 플레이어가 지적한 "스토리가 아닌 글"의 남은 부분이다.

## 변경

- 휴대폰의 위치·체력 막대(`miniBar`)를 맨 위에서는 숨긴다. 그림이 화면 밖으로 스크롤되면 위에서 내려온다. `position:fixed`라 본문을 밀어내지 않는다.
- 휴대폰 상단을 한 줄로 만들었다. 장 이름·빌드 부제를 숨기고, `? 규칙` 버튼은 `?`만 보인다(`aria-label` 유지, 44px 높이 유지).
- 빌드 태그는 하단 `크레딧·제작 정보` 줄에 늘 보인다(펼치지 않아도 된다). 데스크톱 헤더의 빌드 표시는 그대로다.
- 이야기·선택지·판정 규칙·저장 형식은 바꾸지 않았다.

## 측정 (로컬 Chromium, 390×844, 새 게임, 로그)

| 화면 | 본문 첫 줄 y: 이전 → 이후 |
|---|---:|
| 한국어 도입 3/3 | 484 → 386 |
| 한국어 등대 문 `door` | 345 → 247 |
| 영어 등대 문 `door` | — → 283 (`Aduventure` 표제가 버튼과 한 줄에 다 들어가지 않아 두 줄) |

상단 아이콘 줄: 115px → 63px(한국어). 아래로 스크롤하면 막대가 나타나는 것(`miniBar show`, top 0)을 확인했다. 페이지 오류 없음.
