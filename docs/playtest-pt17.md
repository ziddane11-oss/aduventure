# pt17 — 남의 기록이 내 게임에 나타난다, 게임이 당신을 기억한다

## 1. 붉은 쪽지 (비동기 흔적)

다른 모험가가 장면에 남긴 쪽지가 보이고, 나도 한 장면에 한 번 남길 수 있다.

- **단어 조합형만**: [누구·무엇 10개] + [어떻게 5개] + [단서 7개]. 예: "렌 — 의심해라 (단서: 장부)" / "Doubt Ren (clue: the ledger)". 자유 문장이 없어 욕설·개인 정보가 들어올 수 없고, 단어 id로 저장하므로 **한국어·영어 플레이어가 서로의 쪽지를 자기 언어로 읽는다.**
- 장면마다 최근 2개. "제N호의 누군가"로 표시(이름 없음).
- **쓰기**: 기존 피드백 파이프로 `type: "note"`를 보낸다. 기존 doPost가 '응답' 시트에 그대로 적는다.
- **읽기**: Apps Script `doGet(?action=notes)`. 응답이 JSON이 아니면(지금처럼 "alive") **기능 전체가 숨는다** — 게임은 그대로.
- 서버도 단어 목록으로 다시 검증한다. 게임과 스크립트의 단어 목록이 같은지 테스트로 고정했다.

### 켜는 법 (두원 님, 약 5분)
1. '어두벤처 응답' 시트 → 확장 프로그램 → Apps Script.
2. 기존 `doGet` 함수를 지우고 [`gas/notes-doGet.gs`](../gas/notes-doGet.gs) 전체를 붙여 넣는다. **doPost는 건드리지 않는다.**
3. 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포. (저장만으로는 반영되지 않는다.)
4. 웹 앱 주소 뒤에 `?action=notes`를 붙여 열었을 때 `{"ok":true,"notes":[]}`가 보이면 완료. 게임을 새로고침하면 장면에 "✎ 쪽지 남기기"가 나타난다.
- 주의: 기존 doPost가 type을 가려 받는다면 "note" 행이 시트에 안 남을 수 있다. 쪽지를 하나 남긴 뒤 '응답' 시트 맨 아래에 `note` 행이 생기는지 확인한다. ⚠ 기존 doPost 코드는 저장소에 없어 확인하지 못했다.

## 2. 게임이 당신을 기억한다 (첫 화면이 영구히 바뀜)

에필로그 판결이 이후 **모든 회차의 첫 화면 공식 기록**을 바꾼다(`aduventure_verdict`).

| 판결 | 다음부터의 첫 화면 |
|---|---|
| 세온 고발 | "새 촌장 취임 후 첫 폭풍." … **기록자: 기록관 {당신}** / 붉은 손글씨: **"이것도 거짓말이다."** |
| 베른에게 죄 | "새 등대지기, 사고로 부상." … 기록자: 촌장 세온 / **"베른 영감은 아무 짓도 하지 않았다."** |
| 거래 | 기록자: 촌장 세온 · **입회: {당신}** / **"당신도 여기에 서명했다."** |

진실을 밝혀도 기록은 다시 거짓이 된다 — 다음 회차를 다시 쓸 이유.

## 검증 (2026-10-02)

- 자동 테스트 **162개 통과**: 기존 154개 + `tests/notes.test.cjs` 8개. 단어 목록 밖 쪽지 버림·장면당 2개, 서버 없음 → 숨김, 쪽지 표시와 작성(보내는 본문 형식), "alive" 응답 → 숨김, 판결별 첫 화면, 한·영 짝, **Apps Script doGet을 가짜 시트로 실행**(health check 유지, 화이트리스트, 최신순, 장면당 3개, JSONP 콜백 이름 검증), 게임과 스크립트의 단어 목록 일치.
- 현재 공개 스크립트에 `?action=notes`를 보내면 "alive" → 게임에서 쪽지 기능은 숨은 상태로 배포된다.
