# 자유 입력 + 주사위 — 설계 메모 (구현 보류)

개발 바이블 9절 "자유입력 모드(법정 구조)"의 구체화. **지금 구현하지 않는다.** 겸직 허가·비용·학생 안전을 먼저 결정한다.

## 원칙: AI는 번역만, 결과는 주사위
1. 플레이어가 장면에서 하고 싶은 행동을 한 줄로 쓴다(최대 80자).
2. 서버의 AI가 그것을 **판정 하나**로 번역한다: `{ability, skill, dc, verb}` 또는 "이 장면에서 불가능" — JSON 스키마로 강제.
3. 게임 엔진이 기존 규칙(SRD d20 / 2d6)으로 굴린다. 결과 문장은 장면에 미리 써 둔 성공/실패 틀에 끼워 넣는다(AI가 이야기를 지어내지 않음).
4. 채택할 만한 행동은 기존 "제안함"으로 모아 정식 선택지로 승격한다(학생 실명 크레딧 정책과 연결).

## 구조
- 정적 페이지(GitHub Pages)에는 **API 키를 두지 않는다.** 작은 서버 함수(프록시)가 키를 보관하고, 요청 길이·횟수 제한, 금칙어, 장면 키 화이트리스트를 적용한다.
- 저장: 입력 원문은 저장하지 않거나 짧게 보관 후 삭제. 익명 회차 id만.
- 비용: 요청당 짧은 입력·짧은 JSON 출력. 실제 단가는 도입 시점의 요금표로 계산한다(이 문서에 숫자를 적지 않는다).

## 결정해야 할 것
- 겸직 허가(수익화와 무관한 무료 운영이라도 외부 서비스 비용이 생김)
- 미성년자 입력 정책과 보호자 안내
- 장애 시 동작: 서버가 응답하지 않으면 자유 입력 칸을 숨기고 기존 선택지만 남긴다.
