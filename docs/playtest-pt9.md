# pt9 — 선택 기록과 전투 행동의 역할

## 목표

선택을 누르기 전의 시간과 당시 가능한 행동을 함께 기록한다. 이 기록은 재미의 점수가 아니라 관찰·후속 질문을 위한 단서다. 새 삽화나 챕터를 추가하기 전에 전투 행동의 용도를 점검한다.

## 전투 변경

- 렌 전투: 방해를 시도하면 성공·실패와 관계없이 재사용 대기 상태가 된다. 기본공격·받아넘기기·사용 가능한 함정 중 다른 행동을 한 번 하면 다시 사용할 수 있다. 직업별 판정 능력·성공률·피해량은 pt8 그대로다.
- 일반 전투: 방어는 해당 적 공격에 AC +4를 적용하고 다음 기본공격에 피해 +4를 준비한다. 중첩되지 않고, 기본공격이 빗나가거나 특수기·회복을 선택해도 소모된다. 방어 자체는 공격하지 않으며 적에게 명중당하면 피해량은 그대로다.
- 새 설명은 한국어·영어 모두 제공한다. 잠긴 행동과 이미 소모한 자원은 핸들러에서도 검사한다. 반격·방해 대기 상태는 전투 진입, 재시작, 이어하기에서 초기화한다.

이는 반복 행동을 줄이고 방어의 후속 이득을 주기 위한 설계 가설이다. 전체 전투 균형이나 재미가 입증된 변경은 아니다.

## 데이터 읽기 원칙

- 선택 비율은 같은 버전·장면·직업·주사위 규칙·선택 가능 목록을 먼저 구분해 읽는다. 한 사람이 여러 번 누른 행동을 여러 독립 참여자의 의견으로 세지 않는다.
- 체류 시간에는 읽기·망설임·혼란·화면 앞 자리 비움이 섞인다. 길다고 재미있거나 깊게 고민했다고 단정하지 않는다.
- 다시 시작한 이유가 호기심인지 패배·실수인지 구분한다. 재선택 변화는 동일한 선택지가 열렸던 경우끼리 비교한다.
- 표본 3명은 질적 관찰이다. 선택률 90%를 지배 전략의 확정 기준으로 사용하지 않는다.
- pt8에는 상세 행동 기록이 없으므로 pt8과 pt9의 행동 통계를 이미 확보한 것처럼 비교하지 않는다.

## 행동 기록 형식

- 이벤트: `choice`, `combat_action`, `run_start`, `run_continue`, `run_restart`, `decision_unfinished`. 기존 장 완료·사망 이벤트도 같은 익명 회차 형식을 사용한다.
- 공통: `build`, `player_id`, `run_id`. 선택에는 `decision_id`, `seq`, `scene_id`, `choice_id`, `available_ids`, `dwell_ms`, 언어·규칙·직업과 행동 직전 HP·적 의도·남은 자원을 더한다. 캐릭터 이름은 행동 기록에 넣지 않는다.
- 서사 선택 ID는 `장면:원래 선택지 인덱스`다. 조건부 선택을 숨겨도 ID는 바뀌지 않는다. 선택 순서를 수정한 다른 빌드는 별도 비교해야 한다.
- `dwell_ms`는 선택이 가능한 화면의 체류 시간이며 읽는 시간도 포함한다. 숨긴 탭·설문·튜토리얼·주사위 애니메이션 시간은 제외한다. 언어 전환은 시간을 초기화하지 않는다. 측정이 준비되지 않았으면 `null`을 기록하고 플레이를 계속한다.
- 이어하기는 회차 ID를 유지하고 재시작은 새 ID를 만든다. 전투 중 재접속은 기존 안정 장면 저장으로 돌아가므로 순번이 겹칠 수 있다. `decision_id`의 페이지 방문 ID로 구분한다.
- `decision_unfinished`는 페이지를 떠날 때 가능한 범위에서 보내며 수신을 보장하지 않는다. 일시 중단·새로고침일 수 있으므로 포기로 단정하지 않는다.
- 기존 GAS `extra`에 최대 950자 JSON으로 전송한다. 전송·저장 실패가 게임 진행을 막지 않는다.

## 수신 경로 확인

기존 GAS의 `telemetry` 유형, `text` 이벤트 이름, `extra` JSON 문자열을 사용한다. 2026-10-01 합성 검증 `VERIFY_PT9_SCHEMA_20261001`을 보내 응답 시트의 실제 행에서 `build`, `choice_id`, `dwell_ms`가 보존되는 것을 확인했다. 해당 행의 이름은 `NOT_A_PARTICIPANT`이며 참여자 데이터가 아니다. 실제 플레이 경로에서 생성된 기록은 배포 후 별도 확인한다.

## 검증 상태

전투·선택·표시·행동 기록의 Node 테스트를 통합 실행한다. 숨김/설문 시간 제외, 중복 클릭, 기존 저장 호환, 전투 대기 상태와 가능한 행동 목록을 검증한다. 실제 공개 화면과 시트 수신 결과는 배포 PR에 기록한다.
