# 어두밴처(Aduventure) — 아스트라 검토 요청서

> **아스트라에게.** 이 문서는 한국의 고등학교 물리 교사가 혼자(AI 페어 프로그래머와 함께) 만들고 있는 브라우저 텍스트 RPG 「어두밴처 / Aduventure」의 전체 기록이다.
> 우리가 알고 싶은 것은 하나다. **"이 게임의 재미가 스팀에서 돈을 내고 살 만한 재미인가? 아니라면 무엇이 모자란가?"**
> 칭찬은 필요 없다. 냉정하게 봐 달라.

---

## 0. 검토 요청(이대로 읽고 답해 주면 된다)

**역할:** 당신은 스팀에서 인디 내러티브·추리 게임을 수백 개 해 본 사람이고, 리뷰를 쓰기 전에 환불 시간(2시간) 안에 판단하는 평범한 구매자이기도 하다.

**순서(부탁):**
1. 먼저 **스포일러 없이 직접 해 본다** — https://ziddane11-oss.github.io/aduventure/ (휴대폰·PC 브라우저, 한국어/영어 우상단 전환). 최소 30분, 가능하면 사건 1의 판결까지.
2. 그다음 이 문서의 1~8절을 읽는다(5절에 스포일러).
3. 9절의 질문에 답한다. 10절의 형식을 지켜 준다.

**우리가 정의한 "스팀 수익화가 되는 재미":**
- 처음 15분 안에 **"이건 다른 텍스트 게임과 다르다"**는 한 가지가 느껴진다(훅).
- 한 판이 끝났을 때 **"한 판 더"**가 자발적으로 나온다(반복 동기).
- 끝까지 했을 때 **누군가에게 말하고 싶은 장면**이 하나 이상 있다(입소문).
- 환불 시간(2시간) 안에 **"이 값이면 샀다"**가 성립한다(가격 대비 분량·완성도).

## 1. 한 줄 소개

**"공식 기록은 거짓말을 한다. 당신은 그 여백에 붉은 잉크로 반박을 적는 기록관이다."**

판타지 항구 마을 소금여울에서, 촌장이 쓴 '공식 기록'의 거짓을 플레이어가 직접 겪은 증거로 뒤집는 **회차형 추리 텍스트 RPG**. 판(기록 제113호, 114호…)을 거듭할수록 단서·흉터·발자국이 쌓이고, 오판은 영구 기록에 남아 재심으로만 지울 수 있다.

- 장르: 내러티브 추리 + 가벼운 TRPG 판정(D&D 5판 SRD 5.1 일부, d20)
- 플랫폼: 웹(단일 HTML, 설치 없음). 스팀 출시는 데스크톱 포장 예정
- 언어: 한국어·영어 동시(하나의 게임에서 즉시 전환)
- 분위기: 흑백 종이 + 붉은 잉크 하나. 그림은 아직 코드로 그린 초상 초안뿐

## 3. 핵심 루프와 재미 가설

```
장면 읽기 → 선택(판정 d20 / 말 / 증거 / 직업의 길) → 결과
   → 장 끝: 공식 기록 카드 등장 → 「이의 있음」: 거짓 문장을 증거로 뒤집기
   → 단서 조각이 사건 기록장에 쌓임 → 3장 끝: 판결(고발 / 희생양 / 거래 / 보류)
   → 다음 판(기록 번호 +1): 지난 판의 단서·흉터·발자국이 남아 새 길이 열림
```

**우리가 믿는 재미(가설) 5개 — 이게 맞는지가 검토의 핵심이다**
1. **반박의 쾌감:** 공식 기록의 거짓 줄을 붉은 잉크로 긋는 순간(역전재판의 "이의 있음"을 텍스트로).
2. **판이 쌓이는 추리:** 한 판에 진실을 다 볼 수 없다. 판마다 다른 길을 걸어 조각을 모은다(회차형 미스터리, 「아웃터 와일즈」·「오브라 딘 호의 귀환」식 지식 진행을 가볍게).
3. **틀린 판결의 무게:** 증거 없이 고발하면 오판이 영구 기록에 남고, 첫 화면의 공식 기록이 바뀐다. 재심만이 지운다.
4. **실패가 힘이 되는 구조:** 실패한 판정은 '흉터'로 남아 다음 판에 그 기술이 쉬워진다.
5. **메타 반전:** "붉은 손글씨는 누구의 것인가" — 플레이어 자신의 반박, 다른 플레이어의 반박, 앞선 기록관들의 반박이 하나의 이야기로 묶인다(사건 2·피날레).

## 5. 이야기 구조 ⚠ 스포일러

**사건 1 「S는 누구인가」 — 소금여울**
- 1장 잿빛 등대: 폭풍 밤 꺼진 등대. 도굴꾼 렌과 결투 → 난간에서 "렌이냐 렌즈냐" 딜레마. 톱니는 빠진 게 아니라 빼낸 것.
- 2장 검은 코트: 부두 밀수꾼 스컬리. 장부의 돈은 '소금여울 공동 기금'으로.
- 3장 사라진 종소리: 잿돌 수도원, 가짜 수도사, 수문 앞 "사람이냐 증거냐". 편지 뒷면의 붉은 지도 — "{이름} — 도착 예정."
- 에필로그 판결: 촌장 세온이 S. 밀수선을 들여 마을의 겨울을 사려고 등대를 끄게 했다. "고발하면 아이들이 굶는다" vs 진실.

**사건 2 「붉은 손글씨」 — 필사의 마을 먹울**
- 공식 기록 사본의 여백마다 붉은 반박. 글씨가 다 다르다 → **붉은 손은 여럿**(공식 기록을 믿지 않은 모든 사람).
- 필사소장 묵이 매일 밤 반박을 긁어 지운다. 돈은 소금여울 촌장실의 '정서비'.
- 눈먼 낭독가 이레가 지워진 자리를 손끝으로 읽고 다시 쓴다. 봉투를 보낸 것도 이레.
- 판결: 폭로 / 지하에 숨겨 보존 / 묵과 거래(내 기록만 남긴다).

**시즌 1 피날레 「제113호」**
- 이레의 마지막 편지: 3장의 붉은 지도도 그녀가 그렸다.
- 촌장실 서고: 당신 앞에 기록관 112명. 모두 "이 기록에 반박 없음을 확인함"에 서명했다. 제112호만 서명 대신 붉게 "다음 기록관 — {이름}."
- 정서비는 촌장 결재 + 마을 회의 일곱 연서 — 지우라고 돈을 낸 손도 여럿.
- 마지막 선택: 제113호 확인란에 **[붉은 여백] 반박 있음 / [낭독] 이레에게 펜 / [서명] 앞의 112명처럼**.
- 마지막 줄: "붉은 손은 여럿이고, 그중 하나는 당신이다."

| IF 비평가 | 50분 | 92% | 98% |

⚠ **한계:** 가상 플레이어는 규칙 기반 시뮬레이션이다. 글을 읽는 속도·참을성·호기심을 숫자로 흉내 낼 뿐, **재미를 느끼지 않는다.** 실제 사람 피드백은 아직 개발자 본인과 소수의 학생뿐이다. 그래서 이 검토를 부탁한다.

**실제 사람 피드백(지금까지)**
- "정보가 너무 많다" → pt23 덜어내기
- "글만 따라가면 집중이 흩어진다" → pt37 아이캐치
- "이의 있음이 너무 어렵다, 뭘 해야 할지 모르겠다" → pt38

---

## 8. 우리가 아는 약점(솔직하게)

1. **첫 15분의 훅이 약할 수 있다.** 핵심 재미(반박·메타 반전)가 1장 끝(약 4~5분)부터 시작되고, 진짜 반전은 사건 2 이후.
2. **모바일 캐주얼은 한 판에 3장까지 못 간다(32%).** 끊어 하기로 대응했지만 실측 없음.
3. **추론(누가/무엇을/왜)이 너무 어렵다** — 거의 아무도 못 맞힌다. 고칠지, 보너스로 둘지 미정.
4. **그림이 없다.** 초상 9장이 코드로 그린 초안. 스팀 스크린샷 경쟁력이 낮다.
5. **장치가 많다(15개 이상).** 덜어냈지만 여전히 많다. 어떤 게 실제로 재미인지 데이터가 없다.
6. **분량:** 시즌 1을 한 번 쭉 하면 약 40~50분(가상 플레이어 중 이야기 몰입형 42분, IF 비평가 50분 — 회차 포함) + 다른 결말을 보는 회차 플레이. 환불 기준(2시간)보다 짧다. 가격을 얼마로 해야 할지 모른다.
7. **AI와 함께 쓴 글:** 문장은 교사가 검토하지만 톤이 고르지 않을 수 있다.

**스팀 계획(가정)**
- 가격: 저가(커피 한두 잔 값) ⚠추론 — 근거 없음, 검토 요청.
- 순서: 웹에서 다듬기 → 그림·소리 → 사건 3 설계(시즌 2) → 데스크톱 포장 → 상점 페이지 '출시 예정' 먼저 열어 위시리스트 → 데모(Next Fest) → 출시.
- 마케팅: 개발 일지(Threads·유튜브), "물리 교사가 학생들과 만든 게임" 이야기.
