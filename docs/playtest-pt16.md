# pt16 — 모든 싸움을 서사 결투로

## 피드백

pt15 직접 플레이: "확실히 전투는 바꾼 게 좋다. 나머지에도 다 적용하자."

## 변경

2장 스컬리, 3장 가짜 수도사의 숫자 전투(`combat2`·`combat3`)로 들어가던 12개 진입점을 모두 2박자 서사 결투로 바꿨다. 1장 렌 결투(pt15)와 같은 규칙이다: 박자마다 다른 딜레마, 모든 선택에 '걸린 것', 첫 박에서 이기면 둘째 박에 쉬운 마무리, 위저드 전용 선택, 말로 끝낼 길. 같은 틀이 반복되지 않도록 적마다 성격을 다르게 했다.

| 결투 | 1박 | 2박 |
|---|---|---|
| **스컬리**(빠른 단검, 편지에 집착) `scully1`·`scully2` | 박자 읽기(지각) / 탁자 걷어차기(운동) / 편지를 불에 던지는 척(기만) / 등불 끄기(위저드) / 설득 | 기회로 제압 / 뒷문 막기 / **편지를 먼저 낚아챈다 — 증거를 택한다**(판정 없음, 스컬리를 놓침) / S가 누구냐 위협(성공 시 `f_hands` 조각) |
| **가짜 수도사**(느리고 무거운 촛대, 차오르는 물) `monk1`·`monk2` | 촛대 흘리기(운동) / 그림자로 등 뒤(은신) / 횃불로 눈 멀게(위저드) / "너도 버려졌다" 설득(성공 시 조용한 구출) | 기회로 쓰러뜨리기 / 정면 / **싸움 대신 열쇠부터**(은신, 성공 시 조용한 구출) / S가 누구냐 위협(바닷가 사람이라는 실마리) |

- 스컬리를 놓치면 `scullyFled`: 2장 엔딩 "스컬리는 뒷문으로 달아났다. 손에 남은 건 편지뿐이다.", 결과 카드 ✗, 공식 기록은 "도주". 3장 수문의 사람/증거 선택을 2장에서 한 번 예고한다.
- 2·3장 결투에서 HP 0이면 `gameover` — "기록대로 되었다" 기록 카드. 1장만 봉화로 이어지는 예외를 유지한다.
- 위치 카드, 붉은 분위기, 긴장 저음(첫 박 0.8, 마지막 박 1), 쇠 부딪힘·물소리 효과음을 결투 장면에 적용했다.
- 숫자 전투 코드와 `combat`·`combat2`·`combat3` 장면은 이야기에서 연결되지 않지만, 밸런스 시뮬레이터와 기존 전투 테스트가 직접 연다.

## 검증 (2026-10-02)

- 자동 테스트 **154개 통과**: 기존 146개 + `tests/duel.test.cjs` 8개. 기존 테스트 5개는 실패 분기가 결투로 가도록 기대값을 바꿨다(스컬리 결투 화면 확인, 숫자 전투 텔레메트리는 전투 장면을 직접 열어 검증).
  - 이야기의 어떤 경로도 숫자 전투로 들어가지 않는다.
  - 두 결투 모두 모든 갈래가 다음 박·장 엔딩·수문으로 나가고, 모든 선택에 걸린 것, 쉬운 마무리, 위저드 선택이 있다.
  - 스컬리 제압 엔딩, 편지 낚아채기 엔딩·기록·결과 카드, 조용한 구출, 2장 HP 0 게임오버, 한·영 짝.
- 전투 엔진 54조건 결과는 pt10과 동일하다.
- Chromium 390×844(위저드): 두 결투의 1·2박, 위치 카드, 붉은 분위기, 영어 화면 한글 없음, 가로 넘침 없음, 페이지 오류 0.
- **미확인:** 2·3장 결투의 실제 체감 난이도(위저드 근력 판정은 낮다), 소리.
