# pt45 — 본문과 행동에 집중하는 본편

## 문제와 결정

실제 플레이 피드백은 이야기 자체보다 보조 문구와 동시에 보이는 행동 수가 읽기를 방해한다는 쪽이었다. 선택 결과를 미리 설명하는 문구도 서명·판단의 긴장을 약하게 만든다는 의견을 함께 반영했다.

코드에서 확인한 장면은 57개이며, 그중 일반 행동 선택지가 있는 장면은 45개다. 부두·대치에는 이미 4개 접기가 있었지만 `lead` 탐문 거점은 예외였고, 도입부 재플레이 이동 버튼도 상한 밖에 있었다. ‘모든 부두 화면에서 7개가 그대로 보인다’는 주장은 현재 코드와 다르다.

## 변경

- 탐문 거점을 포함해 일반 행동은 최초 4개 이하. 직업 행동과 획득한 단서의 길을 우선하며 기본 행동 한 자리를 보존한다. 나머지는 기존 ‘다른 방법’으로 열고, 행동이나 조건은 삭제하지 않는다.
- 이미 기록한 장면으로 이동하는 재플레이 버튼들은 접힌 ‘기록한 지점에서 시작’에 모았다.
- 기본 선택지에서 확률·난이도·결과 예고와 반복 꼬리표를 제거했다. 잠금 조건과 짧은 직업 표시는 남겼다. 상세 규칙은 기존 숫자 버튼, 전체 도움말은 기존 규칙 버튼으로 볼 수 있다.
- 첫 판정 안내를 두 문장으로 줄이고 확인 여부를 별도로 기억한다. 새로고침·옛 저장 복원 후에도 불필요하게 반복하지 않는다. 숫자 모드를 켰을 때 규칙 패널이 자동으로 튀어나오지 않는다.
- ‘이미 기록한 장면 — 펼쳐 읽기’는 ‘전문 읽기’로 줄였다. 화면별 제안 버튼은 하단 정보 패널 안으로 옮겼다. 위치와 현재 목적, 체력, 증거의 내용은 유지한다.
- 첫 붉은 줄 긋기 후의 설명 세 문단을 제거하고 기존 1장 도입을 짧은 세 페이지로 나눴다. 건너뛰기는 마지막 임무 요약으로 이동한다. 읽던 페이지는 저장하며 언어 전환으로 초기화되지 않는다.
- 마지막 도입 페이지에 세온의 기존 동기 단서를 심었다: ‘곡식과 약을 실은 배까지 끊기면, 마을은 겨울을 못 넘겨.’ 밀수 가담이나 범인 정답을 확정하지 않는다. 다시 하는 플레이어의 접힌 도입에도 이 요약을 보여 준다.
- 한·영 동시 적용. 전투·증거 수집·기록 반박·삽화와 별도 ‘반송된 편지’ 실험의 진행 규칙은 유지했다.

## 검증

`node --test tests/*.test.cjs`: **327 통과, 0 실패**.

`tests/main-clarity.test.cjs`는 실제 렌더와 클릭 핸들러를 실행한다. 45개 행동 장면, 세 직업, 장면별 플래그 조합과 기억 여부를 포함한 **1,044가지 조합**에서 최초 상한과 펼친 뒤 행동 보존을 검사한다. 재플레이 이동, 직업 행동 우선, 잠금 설명, 첫 판정 안내 기억, 도입부 건너뛰기·언어 전환·저장 복원도 검증한다.

기존 테스트의 결과 예고·탐문 예외 기대를 새 동작으로 바꿨다. 경로 시뮬레이터는 새 도입의 ‘다음’ 버튼을 실제로 누른다. 시뮬레이션은 진행 막힘 검사용이며 사람의 재미 평가가 아니다.

보조 문구 수 비교는 동일한 저장 상태로 `CLARITY_METRICS=1 node tests/main-clarity.test.cjs`를 실행했다. 본문과 행동 버튼 이름, 접힌 패널은 제외하고 행동 주석·첫 판정 안내·여파 제목·현재 목적·쪽지/제안 안내의 유니코드 문자 수를 센다. 아래 표는 모든 화면의 총 글자 수가 아니다. 세 표본 모두 첫 판정 안내를 아직 읽지 않은 조건으로 비교했다.

| 표본 | 한국어 이전 → 이후 | 영어 이전 → 이후 |
|---|---:|---:|
| 1장 등대 문 `door` | 81 → 43 | 184 → 98 |
| 2장 부두 `wharf` | 153 → 48 | 313 → 91 |
| 3장 대치 `monk1` | 98 → 57 | 203 → 113 |

## 실제 플레이 확인 동선

1. 처음 시작: 공식 기록에 붉은 줄 → 이름/직업 → 도입 다음/건너뛰기 → 등대 문. 건너뛰어도 마을의 곡식·약과 어선 세 척을 이해할 수 있는가?
2. 탐문 거점: 네 행동과 ‘다른 방법’. 펼치면 남은 행동을 고를 수 있는가? 부두에서 직업·단서 행동이 잘 보이는가?
3. 선택지의 결과 예고를 읽지 않고 고른 뒤 결과를 이해할 수 있는가? 이해가 어려우면 결과 설명을 복구하기 전에 행동 문장과 사전 사실을 점검한다.
4. 다시 온 사람에게는 ‘글이 줄었다’보다 ‘이번에는 스스로 판단했다’는 반응이 생기는가? 실제 플레이어에게 확인할 남은 질문이다.
