# pt30 — 선택지 접기 · 다시 하기 빨리 넘기기 · 사건판 추론

## 왜
pt29 시뮬레이션과 대표 3명 리뷰에서 나온 다음 후보 1·2·3을 추천안대로 진행했다("태스터들 의견이 어떨까 고민하면서").

## 무엇
1. **선택지 접기**: 한 장면에 선택지가 4개를 넘으면 4개만 먼저 보인다.
   - 탐문으로 약속받은 길 → 판정 없이 확정되는 결과 → 지난 판에서 얻은 길(🦋) → 안 가 본 길 순으로 보인다. 조건 없는 기본 길(대화 우선) 한 자리는 늘 남긴다. 나머지는 「▾ 다른 방법 n개 더」 뒤에 둔다.
   - 탐문 거점(dawn2 등)은 고르는 것 자체가 설계라서 접지 않는다.
   - confront에서 모든 조건을 갖춘 경우: 7개 → 4개 + 3개 접힘.
2. **다시 하기 빨리 넘기기**
   - 전에 읽은 결과는 마지막 문단(어떻게 됐는지)만 보인다(「▸ 전에도 이렇게 됐다 — 처음부터 읽기」). 피해·단서 같은 새 정보는 늘 다 보인다.
   - 이미 기록한 장면은 선택지가 기다림 없이 바로 뜬다.
   - **버그 수정**: 「다른 선택으로 2·3장 다시」로 이어서 할 때 '이미 본 장면' 기준이 새로 고쳐지지 않았다. 그래서 지난 판에 본 장면이 접히지 않았고, 간 길 표시와 흉터 기준도 낡은 채였다. 테스터가 지적한 재독 피로의 한 원인이었다.
3. **사건판 추론** — 등대 사건: 누가 · 무엇을 · 왜 (칸마다 보기 4개)
   - 조각 2개 이상부터 할 수 있다. 확인은 **한 판에 한 번**(장 다시 하기도 새 판)이고, **몇 칸이 맞았는지만** 알려 준다.
   - 셋 다 맞으면 「추론 확정」. **조각이 모자라도 판결하러 갈 수 있다**(노가다보다 추리를 보상).
   - 보기는 '그날 밤'에 한정했다. 이야기 속 다른 사실과 겹치는 보기(예: 반출 확인서로 보면 맞을 수 있는 "렌즈를 훔치게 했다")는 억울한 오답이 되므로 뺐다.
   - 결투 타이머 보정: 읽을 시간 = 지금 보이는 결과 길이 + 장면 본문 전체 길이(인물 대사·여파 줄도 함께 뜨므로 넉넉히).

## 대표 테스터 4명 재평가 → 바로 고친 것
첫 구현을 새 빌드로 다시 돌렸다. 대상은 모바일 초보·고등학생·영어권 팬·추리광이고, 실제 문장을 읽혀 평가하게 했다. 지적은 코드로 확인한 뒤 고쳤다.

| 지적 | 확인 | 조치 |
|---|---|---|
| **약속한 선택지가 접힘** — 2장 아침 탐문에서 "내밀 종이 한 장이 생긴다"를 얻고 왔는데 confront의 [영수증]이 접힘 | 맞음: 조건 선택지끼리 같은 점수 → 배열 끝의 영수증이 밀림 | 순위: 탐문으로 약속받은 길 > 판정 없이 확정되는 결과 > 얻은 길 > 안 가 본 길 |
| **대화 길이 늘 먼저 숨음**(scully1 [설득]) | 맞음: 조건 없는 길은 점수가 낮음 | 조건 없는 기본 길 **한 자리 보장**(대화 우선) |
| 영어 "▾ 1 more ways" | 맞음 | "▾ 1 more way" |
| 접힌 결과가 첫 문단이라 **"어떻게 됐는지"가 안 보임** | 맞음 | 마지막 문단(결과)을 보이고, 앞부분을 접는다 |
| **추론 기회가 장 다시 하기에서 안 열림** — 엔딩이 권하는 「2장 아침으로」로 가면 "다음 기록에서 다시"에 막힘 | 맞음: 기록 번호는 처음부터 할 때만 바뀜 | 기회는 **판마다**(장 다시 하기도 새 판). 문구도 "한 판에 한 번" |
| 추론 미끼 "기관을 고치려다 망가뜨렸다 / 사고였다"는 1장 내레이션이 **"수리 중 사고다"라고 단정** → 억울한 오답 | 맞음 | 두 보기 삭제. 미끼는 거짓으로 밝혀지는 것('검은 코트 습격' — 베른이 지어낸 이야기)과 근거 없는 것만 |
| "누가"가 '누가 했나'인지 '누가 시켰나'인지 모호(톱니를 뺀 건 베른) | 맞음 | 칸 이름 **「누가 시켰나」** |
| 정답 "밀수선을 들이려고"는 수단 — 진짜 동기는 마을 겨울 곡식 | 맞음 | "밀수선을 어둠 속에 들여 — 마을 겨울 곡식 값을 대려고" |
| 2장 다시 하기가 **1장에서 한 일을 지움**(톱니 [추궁] 같은 메아리가 사라짐) | 맞음(전부터 있던 문제) | 장 시작 시점의 기록을 저장해 두고, 장을 다시 할 때 앞 장의 일은 남긴다 |
