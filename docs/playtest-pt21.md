# pt21 — 해 지기 전 두 곳 (시간 예산 탐문)

## 왜
- 목표: 한 판 15~20분(쉬는 시간·출퇴근 한 번). 실제 기록상 1~3장 완주가 **5~8분**(시트 telemetry, 7월 빌드) → 고민할 틈이 없었다.
- 장면 수를 늘리는 대신 **고민하는 결정**을 늘린다. 2·3장은 "하나 고르면 장면 끝"이 많았다.

## 무엇
- **2장 시작 「해 지기 전」**: 4곳 중 **2곳만** 들른다 — 세관 사무소 / 기름 가게 / 베른의 오두막 / 언덕 위 촌장 집. (건너뛰기 가능)
- **3장 시작 「수도원 바깥」**: 3곳 중 **2곳만** — 순례자 숙소 / 우편 역참 / 부속 대장간. (건너뛰기 가능)
- 각 장소의 선택지에 "걸린 것"으로 **오늘 밤 어디서 무엇이 열리는지** 미리 보여 준다.
- 들은 것은 **같은 장 안에서** 🦋 꼬리표가 붙은 새 길로 돌아온다(판정 없이 확실한 길):

| 들른 곳 | 열리는 길 |
|---|---|
| 세관(젖은 잉크) | 부두: [입항 기록] → 3번 창고 뒷길 |
| 촌장 집(창문 신호등) | 매복: [신호] → 스컬리 제압 |
| 베른의 오두막(기금 영수증) | 대면: [영수증] → 싸움 없이 2장 끝 |
| 기름 가게(램프 기름) | 스컬리 결투: [기름] → 우위 |
| 순례자 숙소(횃불 둘) | 종탑: [순례자] → 종지기가 입을 연다 |
| 우편 역참(휘파람) | 지하: [휘파람] → 싸움 없이 열쇠 |
| 대장간(쇠꼬챙이) | 물이 찰 때: [쇠꼬챙이] → 철창부터 연다 |

- 탐문과 그 길은 **단서 조각을 주지 않는다** → 사건 구조(여러 판 필요)는 그대로.
- 발자국(pt18)과 맞물림: 다음 판엔 안 가 본 곳이 금색으로 위에 뜬다.

## 검증
- `tests/rounds.test.cjs` 7개 신규(두 곳 제한·재방문 불가·같은 장 회수·조각 없음·이중언어). 기존 2곳 갱신(결투 선택지 '걸린 것' 규칙에 맞춰 새 길에도 걸린 것 추가, 베른 고백 뒤 장면). 전체 193 통과.
- 전투 엔진 시뮬레이션 기준선 동일.
- Chromium 390×844 한국어·영어: 탐문 → 두 번째 → 부두에서 🦋 길 등장, 가로 넘침·콘솔 오류·영어 속 한글 없음.

## 아직 모르는 것
- 실제로 몇 분 늘었는지. 결정 4번 + 읽기라 판당 약 2~4분 증가를 예상 ⚠추론. 15분에 못 미치면 다음 후보: 1장 탐문, 결투 3박.
