## 첫 화면과 규칙 안내

1장 완료 기록이 없으면 **짧은 도입 → 공식 기록 → 기존 두 선택지 → 접힌 다른 사건** 순서다. `다른 사건 (1장 이후 추천)` / `Other cases (recommended after Ch.1)`을 펼쳐야 반송된 편지와 서명 없는 명령 버튼이 보인다. 접힘은 새 방문마다 닫힌 상태이며, 기본 HTML `details`/`summary`를 사용한다.

완료한 사람은 기존처럼 두 사건 버튼이 공식 기록 위에 보인다. 도입 3줄은 신규 사용자에게만 보인다. 완료 판별에는 실제 1장 배지(`1pf`, `1pj`, `1cf`, `1cj`, `1s`), 해당 배지 ID의 유효한 최고 기록, 또는 캐릭터가 있는 1장 엔딩(`ending`) 저장을 사용한다. 배지 지연 저장이나 과거 형식의 최고 기록도 고려한다. 회차 번호·미완료 저장·다른 장 기록만으로 완료를 추정하지 않는다. 이 판별은 온보딩에만 적용하며 기존 게임 내 잠금·분기 조건은 그대로다.

`#returned-letter`, `#unsigned-order`, `letter.html` 직접 진입은 완료 여부와 무관하게 기존 사건을 바로 연다. pt49.1의 언어 우선순위·저장·편지 이동 쿼리도 유지한다.

규칙 창에는 쉬운 설명 한 줄과 `자세한 규칙` / `Detailed rules`만 먼저 보인다. modifier·AC·d20·2d6 분포 등을 설명하는 기존 tutorial 문단은 접힘 안에 그대로 남긴다. 첫 판정의 짧은 안내도 같은 문구를 사용한다. 기본 화면에서는 숫자가 숨겨져 있으므로 `%`가 항상 보인다고 말하지 않으며, 실패가 체력 손실이나 패배로 이어질 수 있어 무조건 계속된다고 약속하지 않는다.

## 첫 클릭 telemetry

기존 GAS의 `page_open`과 같은 POST 형식이다. 페이지 방문이나 첫 클릭으로 게임 run을 만들지 않는다.

```json
{
  "type": "telemetry",
  "scene": "index.html",
  "who": "p0123456789ab",
  "text": "first_click",
  "extra": "{\"v\":1,\"build\":\"v0.7.3-pt50\",\"page\":\"index.html\",\"entry\":\"main\",\"lang\":\"en\",\"player_id\":\"p0123456789ab\",\"visit_id\":\"v0123456789ab\",\"first_click\":\"lie\",\"dwell_seconds\":2.75}"
}
```

- `first_click`: 첫 화면에서 처음 조작한 항목의 고정 코드. `lie`, `believe`, `case_letter`, `case_order`, `rules`, `lang`, `continue`, `feedback`, `case_board`, `sound`, `numbers`, `more`, `other_cases`, `rule_mode`, `credits`.
- 버튼·접힘 요약의 클릭(키보드 활성화 포함), 룰 선택기 클릭 또는 키보드 값 변경을 기록한다. 빈 공간 클릭·스크롤·단순 포커스는 포함하지 않는다.
- `dwell_seconds`: 첫 화면이 표시된 뒤 그 조작까지의 **보이는 시간(초)**. 숨김 탭·`pagehide` 이후·사건 경로로 잠시 벗어난 시간은 제외한다. 밀리초를 1,000으로 나눈 값이며 타이머가 준비되지 않은 예외 경로는 `null`이다. 실제 주의 집중이나 생각한 시간을 뜻하지 않는다.
- 방문당 한 번만 시도한다. 재렌더링·언어 전환·사건 왕복·다시 하기로 초기화하지 않는다. 새로고침은 새 방문 ID를 사용한다. 처음부터 직접 사건 링크로 들어온 방문은 나중에 본편 화면으로 돌아와도 `first_click`을 만들지 않는다.
- 언어 버튼을 처음 누르면 바꾸기 **직전** 언어를 기록한다. 다른 사건 접힘을 먼저 열었다면 `other_cases`가 기록되며 뒤이어 누른 사건 버튼으로 덮어쓰지 않는다.
- 첫 조작 없이 떠나면 `page_open`만 남는다. 없는 첫 클릭을 체류 0초로 처리하지 않는다.
- 기존 `page_open`의 필드는 바꾸지 않았다. 기존 `run_start`(직업 선택·다시 시작)와 `chapter_clear`에는 현재 문서의 `visit_id`만 추가했다. 이어하기는 저장된 `run_id`를 유지하므로 다른 방문에서 완료한 run도 연결할 수 있다.
- 익명 player/visit ID와 고정 코드만 사용한다. URL 전체·브라우저 언어 목록·이름·설문 답변·기타 자유 입력은 추가하지 않는다. `keepalive: true`, 길이 제한과 전송 실패 무시 정책은 기존과 같다.

## 측정 기준

우선 `extra` JSON을 파싱하고 시작 버전별로 집단을 나눈다. 영어 집단은 **최초 `page_open.lang === "en"`**으로 정한다. 첫 클릭으로 한국어로 바꾸어도 같은 집단이며, 이후 이벤트의 언어로 다시 필터링하지 않는다. `letter.html` 또는 `entry !== "main"`인 방문은 본편 첫 화면 전환율 분모에서 제외한다. 완료율은 `run_start.build`로 집단을 고정하고, 추적 기간 내 같은 `run_id`의 클리어는 완료 당시 빌드가 달라도 연결한다.

| 지표 | 계산과 해석 |
|---|---|
| 영어 page_open 대비 본편 run_start 비율 | 분모: `page=index.html`, `entry=main`, `lang=en`인 고유 `visit_id` 수. 분자: 같은 `visit_id`에 `run_start.scene_id=intro`가 하나 이상 있는 방문 수. 직업 선택 완료까지의 **본편 새 시작 전환율**이다. 한 방문의 여러 재시작은 한 번만 센다. Continue는 run_start가 아니므로 별도 first_click=continue 수와 함께 본다. |
| 1장 클리어 비율 | 위 영어 방문에서 시작한 `scene_id=intro`의 고유 `run_id` 수를 분모로 하고, 같은 `run_id`에 `chapter_clear.chapter=1`이 있는 수를 분자로 한다. 클리어는 방문이 달라도 연결하며 `(run_id, chapter)`로 중복 제거한다. 2장 이후부터 재시작한 run은 제외한다. |
| first_click 분포 | 재방문을 포함한 영어 본편 진입 방문 집단에 `visit_id`로 연결한 첫 클릭의 코드별 건수/비율. `first_click` 미수신 방문도 별도 항목으로 보고한다. 수신한 클릭만의 비율과 전체 page_open 대비 비율을 구분한다. `lie+believe`가 주 경로이며 `other_cases`, `case_letter`, `case_order`, `rules`, `lang` 분산도 본다. |
| 첫 화면 체류 | 위 집단의 유효한 `dwell_seconds` 중앙값·상위 분위값과 30초 이내 첫 조작 비율. `null`과 `first_click` 미수신은 별도로 센다. 짧은 시간이 목적 이해를 직접 입증하지는 않는다. |

각 지표는 비율만 쓰지 않고 분자/분모를 함께 남긴다. 이벤트 미수신에는 전송 실패도 섞일 수 있어 미수신을 무클릭·미플레이로 단정하지 않는다. pt49.1에는 첫 클릭과 시작 방문 연결이 없으므로 동일 정밀도의 과거 전환율을 역산했다고 주장하지 않는다. 비교 시 모집 경로와 관측 기간을 맞추고, 시작 직후의 run을 미완료로 확정하지 않도록 같은 추적 기간(예: 24시간)을 둔다. 첫 30초의 목적 이해는 후속 녹화의 발화와 함께 판단한다. 새 telemetry는 반복 방문자를 완벽히 식별하거나 브라우저 밖의 이탈 이유를 추정하지 않는다.

## 패치로 전달받았을 때

`pt50.patch`는 위 기준 커밋 이후의 변경만 포함한 메일 형식 패치다. 깨끗한 작업 트리에서 다음처럼 적용하고 브랜치를 올릴 수 있다. 이 명령은 공개 브랜치로 머지하지 않는다.

```sh
git fetch origin
git switch -c codex/playtest-pt50 3282a5cdae94ef92750adee24927cb55e8d15545
git am /path/to/pt50.patch
node --test tests/*.test.cjs
git push -u origin codex/playtest-pt50
```
