# pt26 — 인물 초상 초안(코드로 그린 도형)

## 왜
"ChatGPT 그림 넣기 전에 초안을 넣어 놔 봐, 느낌 판단할게."

## 무엇
- 인물 8명(세온·베른·렌·스컬리·오도·핍·회색 형제·이레)의 **도형 초상 초안**을 SVG로 직접 그려 게임에 넣었다. 미리보기: `docs/portrait-drafts.png`.
- 규칙(`docs/art-brief.md`과 같음): 회색조, 얼굴 반 명암(왼쪽 어둡게), 막대 눈, 입은 세온만(너무 곧은 한 줄), **붉은 잉크 하나**(세온 찻잔의 한 방울, 베른 붕대, 렌 갈고리 끝, 스컬리 칼날, 오도 횃불 하나, 핍 봉랍, 회색 형제 촛불, 이레 손끝).
- 인물이 나오는 장면의 이름표 옆에 64px 초상.
- **진짜 그림이 오면** `PORTRAIT_FILES`에 경로만 넣으면 초안을 덮어쓴다(나머지는 초안 유지).

## 검증
- `tests/mood.test.cjs` 갱신: 모든 인물에 초안 존재, 각 초안에 붉은색 하나, 파일이 있으면 초안 대체. 전체 210 통과.
- Chromium 390×844: 초상 이미지 로드 확인, 가로 넘침·콘솔 오류 없음.
