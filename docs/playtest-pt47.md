# pt47 — 휴대폰 상단 한 줄(한·영), 직업 카드 줄이기, 종이 장식 제거

## 변경

- **상단 '···' 메뉴(휴대폰)**: 덜 쓰는 버튼(쪽지 🗒·소리 🔊·숫자 🔢, 숫자 모드의 규칙 선택)을 `···` 아래로 접었다. 언어·사건판·규칙(?)은 늘 보인다. 데스크톱은 모든 버튼이 그대로 보인다. 아무것도 삭제하지 않았다.
- **직업 카드(휴대폰)**: '직업의 길'은 이름만 보인다(예: `둘 다 잡는다`). ' — ' 뒤 설명은 데스크톱에서만 보인다. 장면의 직업 선택지 표시는 그대로다.
- **「반송된 편지」 종이**: 왼쪽 위 바인더 구멍 장식이 휴대폰에서 '원본' 앞 글머리표처럼 읽혀 없앴다.

`···`을 누르면 버튼 7개가 모두 보인다(상단 99px). 페이지 오류 없음.

## 검증 중 잡은 것

- `···` 버튼이 휴대폰에서 보이지 않았다. 데스크톱용 숨김 규칙이 파일에서 휴대폰 규칙보다 뒤에 있어 같은 우선순위로 덮어썼다. 휴대폰 규칙의 선택자를 `.crpg .hctrl .hMoreBtn`으로 구체화했고, 테스트가 이 선택자를 확인한다.
- `⋯`(U+22EF)이 이 글꼴에서 `–`처럼 보여 `···`로 바꿨다.
