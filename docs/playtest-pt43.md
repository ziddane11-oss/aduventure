# pt43 — 서명한 뒤에 결과를 만난다

## 바뀐 경험

사용자가 전달한 피드백: 첫 선택지 아래에 자격 정지/유지와 창구 이용 여부가 바로 표시되어, 문장의 의미를 고민하기보다 결과를 고르는 느낌이 든다.

- 첫 서명 화면에서는 여섯 문장 아래의 결과 설명을 제거했다. 선택한 문장, 직접 확인한 사실, 공통 접수 규정, 서명 전 보고서 미리보기는 계속 볼 수 있다.
- 핍이 “내일 첫 배달 전에 다시 올게요”라고 약속한다.
- 서명 후 바로 제재 설명을 보여 주지 않고 다음 날 기록관의 창구로 넘어간다.
  - ‘거부했다’: 창구의 핍 자리는 비어 있고, 밖에서 유리창을 두드리는 소리가 난다.
  - ‘지연되었다’: 핍이 약속한 시간에 와서 안으로 들어온다.
- 이어 핍의 시점으로 옮겨, 문지기가 배달증을 돌려주지 않거나 돌려주는 장면을 겪는다. 보고서와 실제 서명으로 원인을 확인할 수 있다.
- 이미 결과를 경험한 정정 화면에는 효과 설명을 남긴다. 공개 이력과 접수 이력이 소급해서 지워지지 않는다는 안내도 유지한다.
- 하루가 지나는 흐름에 맞춰 한·영 문장의 시제와 접수 시각 표현을 정리했다.
- 실제 출입 판정과 세이브 형식은 동일하다. 기존 체험 저장을 이어 할 수 있다.

## 검증

- 첫 서명에서 여섯 결과 설명이 보이지 않지만 사실·규정·문장은 읽을 수 있는지 검사한다.
- 실제 ‘거부’/‘지연’ 서명에 따라 다음 날 반응이 달라지는지 한·영으로 검사한다.
- 핍의 시점과 정정 화면에서는 결과와 근거가 다시 확인되는지 검사한다.
- 기존 317개 + 새 1개 = 318개 검사 통과.
- 기존 8개 문장 조합의 출입, 원본 보존, 정정, 저장, 본편 세이브 격리 검사를 함께 통과했다.
- 배포 후 공개 브라우저 관찰은 PR에 기록한다.

## 이번에 사람에게 확인할 것

첫 서명 화면을 본 뒤 선택 이유를 묻는다. “자격을 유지하려고”라는 결과 최적화 대신, 핍의 말과 ‘거부/지연’의 의미를 근거로 판단하는지 관찰한다.

다음 날 장면 이후에는 먼저 설명하지 않고, 무엇이 바뀌었고 왜 그렇게 되었는지 묻는다. “몰랐던 벌칙에 당했다”는 반응과 “내가 쓴 문장을 뒤늦게 이해했다”는 반응을 구분한다. 결과 설명을 늦췄다는 사실만으로 재미가 좋아졌다고 판단하지 않는다.
