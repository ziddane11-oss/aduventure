# pt13 — 「S는 누구인가」: 회차를 넘는 미스터리

## 목적

pt6 테스터 3명과 pt11 직접 플레이가 같은 신호를 냈다. 선택의 고민이 적다. 원인은 대부분의 선택이 판정 확률 고르기이고, 갈래가 곧 같은 장면으로 합쳐진다는 데 있다. 이번 빌드는 짧음을 반복 플레이의 이유로 뒤집는다. **한 판으로는 S의 정체에 닿지 못하고, 다른 쪽을 골라 본 판의 조각을 합쳐야 결론을 내릴 수 있다.** 설계안의 pt13(조각·기록장·인물 카드)과 pt14(고발 에필로그)를 한 빌드로 묶었다. 초상화는 테스트 뒤로 미뤘다.

## 진실과 인물

- **S = 촌장 세온.** 죽어 가는 어촌을 밀수로 버티게 하고, 등대는 배가 들어오는 밤에만 꺼지게 했다. 주인공은 쓸 만한 사람인지 시험받았다.
- **등대지기 베른**은 S를 감싸려고 "검은 코트" 거짓말을 했다(미끼 용의자).
- 이름이 없던 인물에 이름을 붙였다: 세온(촌장), 베른(등대지기), 오도(종지기), 핍(배달부). 1장 열쇠에 세온의 글씨로 된 꼬리표가 붙는다.
- 장면 위에 인물 띠(이름·역할)를 표시하고, 처음 만난 인물은 사건 기록장에 영구 기록된다(`aduventure_met`).

## 조각 8개 — 서로 배타적인 갈림길 한쪽에서만

| 조각 | 얻는 곳 | 가리키는 쪽 |
|---|---|---|
| `f_ren_keeper` 렌: 베른이 렌즈를 사려 했다 | 1장 난간 — 렌 | 베른 (미끼) |
| `f_receipt` 촌장실 비품 반출 확인 — 세온 | 1장 난간 — 렌즈 | 세온 |

| `f_hands` 줄질한 손은 펜 쥐는 마을 사람 | 2장 톱니 추궁 | 세온, 베른 아님 |
| `f_addressee` [결정적] 편지 수신인은 세온 | 3장 수문 — 사람 | 세온 |

- 결론 조건: 결정적 조각 1개 + 베른의 고백 + 조각 4개 이상. 조각은 기존 지식(lore) 저장소에 회차를 넘어 쌓인다.
- 조각을 주는 선택지에는 `◇ 아직 못 본 조각` / `◆ 이미 본 조각`을 표시한다. 대가는 '걸린 것'으로 보이지만, 무엇을 알게 될지는 숨긴다.
- 헤더의 🔎 **사건 기록장**: 용의자 3명(세온·베른·렌)의 의심 막대, 조각 8칸(못 본 칸은 얻는 곳 힌트), 결론까지 남은 조건, 만난 인물.

## 에필로그 「S」

결론 조건을 채우면 3장 엔딩에 "소금여울로 돌아가 결론을 내린다"가 열린다. 채우지 못하면 남은 조건을 보여 준다. 촌장의 서재에서 세 가지 중 하나를 고른다. 모두 판정 없이 '걸린 것'을 보여 준다.

| 선택 | 결과 | 도감 |
|---|---|---|
| [고발] 세온이 S다 | 진실이 밝혀지고, 겨울의 곡식과 약이 끊긴다 | `4t` 진실의 대가 |
| [희생] 스스로 나선 베른에게 죄를 씌운다 | 마을은 버티고, 죄 없는 노인이 끌려간다 | `4b` 노인의 희생 |
| [거래] 알고도 덮는다 | 마을도 진실도 그대로, 다음 '시험'은 당신이 낸다 | `4d` S의 사람 |

엔딩 도감은 9 → 12개. 결과 카드에 4장 행을 추가했다.

## 호환

- 저장 형식 `v: 1`, 기존 장면 키는 그대로. 새 장면 `accuse`·`ending4`(4장 = 에필로그, 등대 무대·1장 배경음 테마).
- 새 선택지는 배열 끝에 추가했다(`intro2`). 3장 수문 두 선택지는 같은 인덱스를 유지한 채 결과 문단으로 바뀌었다. 텔레메트리 `choice_id`는 이전과 비교할 수 있다. 결론으로 가는 버튼은 `case:accuse`로 기록한다.
- 기존 지식·유물·도감 저장 키와 의미는 유지한다.

## 검증 (2026-10-01)

- 자동 테스트 **123개 통과**: 기존 108개 + `tests/case.test.cjs` 15개.
  - 모델이 게임이 실제로 주는 조각과 일치하는지 확인했다.
  - 1회차의 모든 선택 조합(4×4×2, 고백 시도 여부)에서 결론이 불가능하다.
  - 결론에 2판으로 닿는 경로가 있고, 어떤 1회차 뒤에도 3판 안에 닫을 수 있다.
  - 고백의 조각 수 조건, 조각 표시(◇/◆), 수문의 결정적 조각, 3장 엔딩의 잠금·해제, 세 결말의 도감, 인물 띠와 기록장(한·영), 새 문자열의 한·영 짝과 영어 쪽 한글 0을 확인했다.
- 판 수 모형(선택을 균등하게 무작위로 고르고 가능하면 고백, 2만 회): **2판 80.4% · 3판 17.9% · 4판 1.5%**. 1장 설득을 50%로 고르는 경우 2판 64.6% · 3판 30.4%. 실제 플레이어 분포가 아니다.
- 전투 54조건 결과는 pt10과 동일하다.
- Chromium 390×844: 인물 띠, 고백 선택지(◇·걸린 것), 기록장, 영어 에필로그·결과 카드·기록장에 한글 없음, 가로 넘침 없음, 페이지 오류 0.
- **미확인:** 실제 플레이어가 두 번째 판을 자발적으로 시작하는지, 고발 장면에서 실제로 고민하는지. 이번 테스트의 측정 질문이다.

## 남은 문제

- 조각 힌트가 얻는 곳을 바로 알려 준다. 너무 친절하면 추리가 체크리스트가 될 수 있다.
- 세온의 정체는 1장 꼬리표부터 깔려 있어 빨리 눈치챌 수 있다. 베른 쪽 미끼가 충분히 무거운지 관찰이 필요하다.
- 초상화(2단계)는 테스터가 인물을 헷갈려 하면 용의자 3~4명부터 넣는다.
