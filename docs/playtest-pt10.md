# pt10 — 전투 규칙의 일관성과 비교 가능한 시뮬레이션

## 목적과 범위

렌 전투와 특수기가 주사위 규칙의 피해 계산을 우회하던 문제를 고친다. 렌도 방어도(AC)에 따라 명중을 판정한다. 같은 전투를 d20과 2d6에서 비교하고, 그 차이를 설명할 수 있게 한다.

이번 빌드는 전투 기반 수정이다. 패배 후 임시 신호불, 렌즈와 렌 사이의 선택, 철사의 다른 용도, 핵심 단서의 무판정 제공은 다음 서사 변경으로 남긴다. 승률을 재미의 점수로 해석하지 않는다.

## 구현 원칙

- 피해 주사위와 추가 피해는 선택한 규칙의 함수로 계산한다. 렌의 공격·방해·함정, 마법 화살, 강타 추가 피해, 준비한 반격을 포함한다.
- 렌의 의도 피해는 AC 명중 후에만 적용한다. 방해 실패의 추가 피해도 빗나간 공격에는 생기지 않는다. 렌 의도 공격은 기존 예고 피해 범위를 유지하며 치명타 추가 피해를 만들지 않는다.
- 2d6 전투는 기존 `AC + 6` 변환을 제거하고, 다른 숙련 판정과 같은 `2d6 + 능력 보정 + 1`을 `toTarget(AC)`와 비교한다. 기본 공격 피해에도 능력 보정을 포함한 뒤 절반으로 올림한다. 서사 판정 DC는 바꾸지 않는다.
- 2d6의 특수 피해·반격·전투 중 회복도 같은 크기로 환산한다. 렌 HP는 모든 직업과 규칙에서 16에서 14로 조정한다. 직업별 숨은 보정은 추가하지 않는다.
- 한국어·영어 행동 설명은 현재 규칙에서 계산한 범위를 표시한다. 기존 저장 형식과 익명 행동 기록은 유지한다.

## 시뮬레이션 읽는 법

사용자가 제공한 Claude 시뮬레이터를 바탕으로 실제 `index.html`의 규칙과 전투 핸들러를 실행한다. 전투 알고리즘을 별도로 복제하지 않는다. React의 상태 반영과 소리·텔레메트리는 메모리 모형으로 대체한다.

```sh
node --test tests/*.test.cjs
node tests/balance-sim.cjs index.html 3000 20261001
node tests/reach-sim.cjs index.html 3000 20261001
```

두 도구에 `--json`을 붙이면 원시 집계를 얻는다. 시드·소스 SHA-256·조건별 판수를 출력한다. 같은 시드라도 코드가 주사위를 소비하는 순서가 달라지므로 변경 전후의 개별 회차가 일대일로 같은 운을 갖는 것은 아니다.

- 전투 표는 만피, 특수기 2회, 숨 고르기 1회, 준비된 반격 없음에서 시작한다. 함정은 표시된 조건에만 있으며 첫 턴에 사용한다.
- 기준 행동은 강타 예고에 받아넘기기, 그 외에는 기본 공격이다. 공격만, 방해 혼합, 방해와 방어 반복도 비교한다. 최적 전략 탐색이나 실제 테스터 통계가 아니다.
- 80턴 내 끝나지 않으면 미해결이다. 승리로 취급하지 않고 분모에는 포함한다. 전체 평균 턴과 승리한 전투만의 평균 턴을 따로 출력한다.
- 장면 도달률은 첫 실패에 운명 주사위를 쓰고, 수리에서는 성공 확률이 가장 높은 선택을 한다는 가정이다. 이동 처리·선택은 작은 모형이므로 브라우저 전체 동작 검증을 대체하지 않는다.
- `peaceful`은 렌 재회 선택지가 열릴 조건이며 실제 2장 재회 관람률이 아니다. `fixed`는 완전 수리이고, 파괴 단서 대사를 실제로 본 것과 별도로 집계한다. 선택 문구가 바뀌면 단서 지표도 다시 검토해야 한다.
- 전투 외 피해로 HP가 0이 되어도 엔딩으로 가는 기존 동작은 별도 지표로 드러낸다. 이번 전투 수정에서 몰래 승패 규칙을 바꾸지 않는다.

## 목표와 남은 문제

제안된 렌 기준 승률 65~85%는 임시 점검 범위다. 전사의 HP 12·AC 16과 다른 직업의 낮은 체력·방어도 차이를 고려하면 여섯 조건 모두를 이 범위로 만드는 것은 별도의 직업·전투 설계를 요구한다. 한 행동 방침의 수치에 맞추기 위한 직업별 적 보정은 하지 않는다.

전사의 쉬운 전투, 2·3장의 짧은 전투, 장마다 특수기가 회복되어 아낄 이유가 약한 문제는 남는다. 다음 재미 검증은 승리 자체보다 무엇을 지켰고 잃었는지가 이후 장면을 바꾸는지에 둔다.

## 검증 상태

- 자동 테스트 81개 통과: 렌의 AC 경계, 빗나간 공격의 피해 없음, 방해·함정의 적 행동 취소, 규칙별 특수기·회복·반격, 한국어·영어 수치 표시, 기존 저장·행동 기록 회귀 검증.
- 시뮬레이터의 같은 시드 반복 결과 일치, 0턴 제한 시 미해결 처리, 집계 분모 확인.
- 공개 Pages의 배포·화면 확인 결과는 배포 PR에 별도 기록한다. 이 문서의 자동 검증을 휴대폰 실기기나 전체 20분 세션 확인으로 해석하지 않는다.

공개 확인에서 전투 시작 로그가 언어 전환 후에도 이전 언어로 남는 문제를 발견해 이중언어 데이터로 수정했다. 전환 회귀 테스트를 추가했으며 시뮬레이션 결과는 동일하다.
