## 무엇 (기능은 빼지 않고 숨긴다)
1. **선택지 꼬리표 1개**: 우선순위 재심 잠금 → 🦋 단서 → 유물/기억 → 직업의 길 → 새 단서 조각 → 발자국. 판정 선택지는 같은 꼬리표 안에 **쉬움 / 반반 / 어려움**(70%↑ / 40~69% / 40%↓). 판정 없는 선택지는 "걸린 것" 한 줄이 곧 꼬리표(🦋·재심 잠금은 그 줄 앞에).
2. **숫자는 기본 숨김**: 머리줄의 🔢 "숫자 보기"를 켜면 확률·능력치·AC·운명·강타·규칙 선택(SRD/2d6)이 예전처럼 전부 보인다(`aduventure_numbers`에 저장).
3. **장치는 회차마다 하나씩**: 2번째 기록 발자국 → 3번째 흉터 → 4번째 붉은 쪽지. 열리는 기록의 도입에 "이번 기록부터 — …" 한 줄.
4. **결정적 한 줄은 크게**: 사건 2 서가의 "제113호부터 제N호까지. 전부 당신이 고쳐 쓴 기록이다."를 크고 붉게, 천천히.
