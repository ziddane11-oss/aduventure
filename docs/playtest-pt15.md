# pt15 — 막 누르지 않게: 서사 결투, 갈림길로 바로 가기, 위치 카드, 상황 효과음

## 피드백 (pt14 직접 플레이)

- 소리가 들어가니 좋다. 상황마다 더 풍부했으면.
- 위쪽 그림이 바뀌는 게 존재감이 없다. 내가 어디서 뭘 하는지 보였으면.
- S가 궁금했다. 그런데 다음 회차는 성질이 급해서 막 눌러 엔딩을 보려 했다.
- 전투는 아직 모르겠다. 아무거나 누르게 되고 고민하지 않는다.

## 선례 조사와 판단

「Sorcery!」(inkle)는 읽고 거는 전투로 주목받았지만, 리뷰에서는 **전투가 가장 약한 요소**(이분법적, 반복적)로, 같은 이벤트 반복은 **탐험의 재미를 단조로움으로 바꾼다**는 지적을 받았다. 가장 칭찬받은 건 싸움을 **피하는** 선택지였다. 「Blades in the Dark」는 굴리기 전에 위험과 효과를 먼저 말해 주는 방식이다. 결론: 전투를 깊게 만들지 말고, **짧게, 박자마다 다른 딜레마, 피할 길 포함, 걸린 것을 미리 보여 주기**.

## 변경

| 장치 | 내용 |
|---|---|
| **렌과의 서사 결투** | 1장 렌 전투(같은 4버튼 반복)를 2박자 서사 장면 `duel1`·`duel2`로 대체했다. 1박: 받아낸다(운동) / 등 뒤로(은신) / 서리(위저드 전용, 비전학) / 다시 말 건다(설득). 2박: 기회를 밀어붙인다(앞서 이겼을 때, 쉬움) / 정면 끝장 / 철사로 몬다(판정 없음, 철사 소모) / 누가 보냈냐 위협(성공 시 "베른 영감" 조각). 모든 선택에 '걸린 것', 모든 갈래는 난간·등실·봉화로 끝난다. 실패 피해로 HP 0이면 `ifDown`으로 봉화 경로. |
| **갈림길로 바로 가기** | 이전 회차에 도달한 갈림길이 있으면 1장 시작에서 `⤳ 렌과 마주치는 계단부터` / `⤳ 3장 수문 앞부터`. 수문으로 가면 3장 시작처럼 체력·운명·특수기를 회복한다. 텔레메트리 `jump:stairs`·`jump:rescue`. |
| **본 장면 접기** | 이전 회차에 본 장면은 첫 문단만 보이고 `▸ 이미 기록한 장면 — 펼쳐 읽기`. 이번 회차 시작 시점의 기록(`aduventure_seen`)으로 판단해, 첫 회차에는 접지 않는다. |
| **위치 카드** | 그림 위에 `📍 장소 · 장 · 지금 하는 일`(예: "렌과 싸우는 중 — 갈고리가 올라간다"). 싸움은 붉게, 정적(난간·수문·봉화)은 어둡게, 결말은 밝게 물든다. 휴대폰에서는 그림과 카드가 함께 위에 고정된다. |
| **상황 효과음** | 문 삐걱(등대 문·창고·지하·서재), 바람(계단·난간·종탑), 쇠 부딪힘(결투), 톱니(등실), 불(봉화), 웅성거림(선술집), 둔탁함(대면), 물(수문), 조각을 얻을 때 펜 긋는 소리. 모두 WebAudio 생성, 파일 없음, 소리를 켠 동안만. 결투 장면은 긴장 저음 80%·100%. |

기존 렌 숫자 전투(`combat`)는 장면 데이터와 전투 코드를 남겨 두었다. 이야기에서는 더 이상 연결되지 않고, 밸런스 시뮬레이터와 기존 전투 테스트가 이 코드를 직접 연다. 2·3장 전투는 그대로다.

## 검증 (2026-10-02)

- 자동 테스트 **146개 통과**: 기존 133개 + `tests/duel.test.cjs` 13개. 기존 렌 전투 UI 테스트 7개는 [전투] 버튼 대신 전투 장면을 직접 열도록 바꿨다(행동 검증 내용은 그대로).
- 전투 엔진 54조건 결과는 pt10과 동일하다(엔진 미변경).
- 도달률(시드 20261001, 3,000회, 결투는 첫 선택지 고정 정책): srd20 바로 전투 경로에서 결투 패배 → 봉화가 파이터 0.5% · 로그 10.1% · 위저드 22.0%(이전 숫자 전투 2.6% · 16.0% · 18.8%). 위저드는 실제로는 서리 선택지를 고를 수 있어 모형보다 낮을 것이다.
- Chromium 390×844: 결투 두 박자, 위치 카드와 붉은 분위기, 긴장 저음, 2회차 첫 장면 접기와 갈림길 버튼, 갈림길 이동, 스크롤 중 무대 고정(top 6px), 페이지 오류 0, 가로 넘침 없음.
- **미확인:** 실제 귀로 들은 효과음 품질, 휴대폰에서 소리 겹침, 결투가 실제로 "고민"을 만드는지.
