# pt24 — 몰입 패치(분위기)

## 왜
덜어내기(pt23) 다음 단계. 참고: 80 Days(흑백 실루엣·굵은 제목), Reigns(도형 초상), ALTER EGO(회색조 + 강조색 하나, 종이 질감). 그림은 나중에 ChatGPT로 — 이번엔 코드로 할 수 있는 분위기만.

## 무엇
1. **색**: 먹색 회색조 + 양피지 + **붉은 잉크 하나**(`--red`). 파랑·보라 강조색을 회색·붉은색으로 정리. 배경에 옅은 종이 결(SVG 노이즈).
2. **무대 흑백**: 장면 그림(SVG/삽화)을 회색조로. 붉은색은 의미 있는 곳(반박·오판·쪽지)에만 남는다.
3. **장소 이름을 굵게**: 위치 카드의 장소명을 굵은 제목체(Black Han Sans / Oswald)로 크게 — 80 Days식 장면 제목.
4. **문단이 차례로 번진다**: 장면 글이 문단 단위로 0.8초 간격으로 나타나고, 선택지는 마지막 문단 뒤에 나타난다(나타나기 전엔 누를 수 없음). **글을 한 번 누르면 즉시 전부.** 움직임 줄이기 설정이면 애니메이션 없음. 사건 2 서가의 붉은 한 줄도 문단 뒤에 등장.
5. **초상 자리**: `PORTRAITS`에 경로만 넣으면 인물 이름 옆에 초상(자동 흑백). 지금은 비어 있어 표식만. 그림 지시서: `docs/art-brief.md`(공통 화풍 블록 + 인물 8명 + 장면 4개 프롬프트).
