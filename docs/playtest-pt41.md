# pt41 — 가독성과 세 인물 초상

## 적용한 범위
- 세온·베른·렌을 잉크 판화풍 초상으로 교체. 각 512×512 WebP, 세 파일 합계 약 110 KiB.
- 본문 구조는 유지하고 보조 글씨·선택지·공식 기록의 가독성을 개선.
- 이미 방문한 길의 선택지 전체 opacity .55 제거. 선택 가능한 길은 선명하게 유지하고 왼쪽 테두리로 구별.
- 초상 104px(작은 화면 88px), 이름·역할을 두 줄로 표시. 네트워크 이미지 실패 시 기존 도형 초상으로 복귀.
- 제작·모집 문구는 접을 수 있는 크레딧으로 이동. 기존 참여자·SRD 표기는 유지하고 생성 초상 출처를 한·영으로 추가.
- 원본 생성 이미지에 의미를 바꾸는 후처리를 하지 않음. 배포 파일은 크기/포맷만 최적화.
- 대사, 판정, 분기, 저장 데이터 형식은 변경하지 않음.

## 제작과 검증
- 이미지: ChatGPT 내장 이미지 생성 도구. 상세 프롬프트: [portrait-prompts-pt41.md](portrait-prompts-pt41.md).
- 자동 검사: 기존 309개 통과. CSS/이미지 교체용으로 구현을 그대로 복제하는 새 테스트는 추가하지 않음.
- 기존 초상 교체 테스트의 fixture는 값이 들어 있는 PORTRAIT_FILES도 교체하도록 수정.
- 실제 공개 화면 확인 결과는 PR 본문에 기록.
- 자동 검사는 재미나 구매 의사의 증거가 아님. 모바일 실기는 별도 확인 대상.

## 신규 플레이어 관찰 — 3명, 수정, 새 3명
이번 버전을 처음 보는 미스터리·텍스트 게임 이용자를 대상으로 1명씩 진행한다.
모집 메시지 전송·보상 지급·인터뷰는 아직 실행하지 않았다.

### 시작 전에
- 진행자가 게임의 정답이나 '혁신적인 게임'이라는 기대를 말하지 않는다.
- “평소처럼 플레이해주세요. 막히면 생각을 말해주셔도 됩니다.”만 안내한다.
- 실제 계획 중인 판매 가격과 포함 분량을 동일하게 제시한다. 임의 가격을 현재 정가처럼 말하지 않는다.

### 기록할 것
| 관찰 | 기록 |
|---|---|
| 처음으로 거짓 기록을 직접 고친 시점 | 경과 시간, 스스로 발견/도움 여부 |
| 글씨·선택지 때문에 멈춘 곳 | 화면/문구, 읽기 어려움과 뜻의 어려움 구별 |
| 세온·베른·렌을 다시 만났을 때 | 이름이나 역할을 기억하는지, 초상으로 알아보는지 |
| 첫 반박 | 근거를 이해해서 선택했는지, 무작위로 눌렀는지 |
| 그만두고 싶은 순간 | 실제로 멈춘 화면, 이유를 원문으로 |
| 끝난 뒤 행동 | 자발적 재시작/다른 길 확인/종료 |
| 판매 가격을 알려준 뒤 | 살/안 살 이유, 가장 아까운 부분 |

### 종료 후 질문
1. 친구에게 이 게임을 한 문장으로 설명한다면?
2. 가장 고민한 선택은 무엇이고 왜 그랬나?
3. 재미있었지만 다시 하고 싶지 않다면 무엇 때문인가?
4. 제시된 가격으로 산다고 생각할 때 가장 걸리는 부분은?
5. 지금 하나만 바뀐다면 무엇이어야 하나?

### 두 차례 후 판단
- 3명 반응은 질적 단서이며 시장 비율·성공 확률로 계산하지 않는다.
- 진행 막힘·문구 혼동 등 반복된 문제부터 수정한다.
- 두 번째 그룹에서 같은 문제가 사라졌는지 확인한다.
- 초상을 칭찬하는지와 게임을 더 하고 싶어 하는지를 별도로 기록한다.
- 상점/Playtest 준비와 유료 출시 판단을 구별한다.

## 다음 실험 가설 — 내가 서명한 기록이 나를 가둔다
사용자의 추가 목표: 익숙한 완성도를 넘어, 관습을 깬다는 체감을 주는 게임.
아래는 제안이며 pt41 본편에 구현되지 않았다. 독창성·재미·호평은 아직 검증되지 않았다.

### 뒤집을 관습
- 기존: 기록관은 다른 사람의 거짓말을 조사하고 판정한다.
- 실험: 자신이 만든 문장이 다음 역할의 권한과 선택지를 결정하고, 그 기록을 자기 손으로 반박한다.

### 10분짜리 실험
1. **기록관, 약 3분.** 같은 사건의 관찰 사실 3개를 보고 한 문장을 작성·서명한다. 완전한 자유 입력 대신 근거가 있는 짧은 구절을 고르고, 사실/추정을 분리해 표시한다. 플레이어의 실제 선택과 서명을 저장한다.
2. **기록 속 당사자, 약 4분.** 예컨대 배달부 핍으로 시점이 바뀐다. 앞서 '고의로 배달을 거부했다'고 적었다면 우편 취급 자격을 잃어 공식 전달 경로가 닫힌다. UI는 잠금 원인으로 플레이어의 원문·서명·기록 번호를 그대로 제시한다. 숨은 주사위나 무관한 벌로 길을 막지 않는다. 반대 진술·증거 확보 등 적어도 두 경로는 남긴다.
3. **자기 문서에 이의, 약 3분.** 자신의 기록을 증거와 대조한다. 유지/정정/판단 유보가 모두 가능하며, 정정할 경우 처음의 서명과 정정 이력을 함께 남긴다. 누락된 관점이 추가되는 것이지 앞서 관찰한 사실을 뒤집어 속이는 것이 아니다.

### 단순 재심과 다른 점
기존 재심은 서사의 결론을 바꾸는 기능이다. 이 실험은 플레이어가 작성한 문구가 다음 역할의 실제 가능한 행동을 바꾸는 규칙을 포함한다.
정답을 알아맞히는 시험이 되지 않도록 같은 증거에서 가능한 판단과 유보를 열어 둔다. '정정하면 항상 더 큰 피해' 같은 일방적 처벌도 피한다.

### 실험에서 확인할 것
- “내가 써서 이 길이 막혔구나”를 설명 없이 알아차리는가?
- 전에 없던 새 증거를 보는 것보다 '내 문장을 적용받는 경험'을 핵심으로 기억하는가?
- 자신의 문장을 지우거나 유지하는 순간 실제로 망설이는가?
- 한 가지 단어를 바꿔 결과를 다시 확인하려 하는가?
- 인과관계를 모르거나 정답이 강요된다고 느끼면 제시 방식/규칙을 다시 만든다.

### 작업 한계
한 사건·세 인물·세 문장·두 역할만으로 만든다. 새 시즌, 무한 생성, 다른 플레이어 연결, 실제 저장 삭제는 넣지 않는다.
“세계 최초”, “반드시 찬사를 받을 것”이라는 주장은 하지 않는다.
