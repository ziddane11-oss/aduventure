# pt48 — 서명 없는 명령 / The Unsigned Order

## 목표

「반송된 편지」의 다음 사건에서 같은 규정을 두 번 다르게 읽게 한다. 기록관이 서명한 반출 규정이 진료소의 약품을 막는다. 이후 플레이어는 촌장 명령서에도 그 규정을 적용할 수 있다. 반전의 해법이나 미래 결과를 선택지 아래에 미리 알려 주지 않는다.

## 구현

- 본편 시작 화면과 「반송된 편지」 결말에서 진입. 독립 주소는 `#unsigned-order`.
- 첫 서명에서 적용 범위(동일 적용 / 촌장실 직인 대체)와 긴급 반출(발행인 서명 / 주민 공동 보증)을 고른다.
- 진료소 명령과 촌장실 이관 명령을 순서대로 받는다. 규정 한 줄과 명령서 한 줄을 직접 골라 이의서에 인용한다.
- 긴급 반출 예외는 **진료소로 보내는 약품**에만 해당한다. 촌장실 보관을 위한 이관에는 적용되지 않는다.
- 잘못된 인용은 근거를 설명하고 재시도를 허용한다. 촌장실 직인을 인정했다면, 서명이 없다는 이의에 자신이 서명한 예외 조항이 돌아온다.
- 정정은 미집행 건에만 적용된다. 원본, 서명, 정정 시점과 문장, 이미 생긴 진료 지연은 남는다.
- 결말은 약품의 오전/오후 도착과 촌장실 이관의 보류/집행을 각각 기록한다. 이관을 막아도 촌장의 다음 적법한 명령까지 막는 영구 승리로 묘사하지 않는다.
- 기존 사건을 완료한 경우 서명과 실제 배달 자격 결과만 이어받는다. 핍의 정지를 임의로 해제하거나 베른의 석방을 만들어 내지 않는다.
- 별도 저장 키 `aduventure_unsigned_order_v1`. 한국어·영어 전환과 새로고침에 선택·이의서·정정 초안이 유지된다. 본편 타이머는 사건 플레이 중 멈춘다.
- 문서 선택 표시는 붉은 밑줄과 `aria-pressed`. 700px 이하에서는 두 문서가 세로로 쌓인다. 기존 아홉 초상화와 pt47 본편 모바일 개선을 유지한다.

## 규정 검증표

| 처음 서명한 조항 | 진료소 공동 보증 인용 | 촌장 명령의 서명 공란 인용 |
|---|---|---|
| 동일 적용 / 엄격 | 승인 불가 | 이관 보류 |
| 동일 적용 / 공동 보증 | 오전 반출 | 이관 보류 |
| 직인 대체 / 엄격 | 승인 불가 | 직인 대체 조항으로 기각 |
| 직인 대체 / 공동 보증 | 오전 반출 | 직인 대체 조항으로 기각 |

모든 조합에서 의사의 서명을 기다리거나 이관을 집행하여 진행할 수 있다. 진행 중 정정한 조항은 이후의 이의에 적용되며 과거 반출 결과를 바꾸지 않는다.
